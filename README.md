# N2 道場

JLPT N2（2027-07-04）每日学习网页：听力、读解、单词语法（带アクセント）、跟读、真题题型闯关、文化、日本の歌。

网页：https://gabrielteufelchen.github.io/n2-dojo/

## 文件结构

| 路径 | 内容 | 可以改吗 |
|---|---|---|
| `index.html` | 整个网页（样式 + 脚本）。头尾的 `<!doctype>…<body>` 外壳是同步脚本自动加的，别删 | 可以 |
| `packs/<日期>.json` | 每天一套教材 | 可以（改错字、补讲解） |
| `packs/index.json` | 教材日期列表 | 新增教材时要同步加日期 |
| `songs/index.json` | 「日本の歌」栏目 | 可以 |
| `audio/<日期>/day-*.mp4` + `index.json` | VOICEVOX 配音（整天一个文件，index.json 记每句的起止秒数和语调） | **不要改**，由作者电脑上的 VOICEVOX 生成 |
| `tools/DAILY.md` | 教材的完整内容规范（字段、题型轮换、讲解要求） | 参考 |
| `tools/check.js` | 教材检查：`node tools/check.js packs/2026-10-25.json` | 参考 |

## 改内容的规则

1. **日语正文里每个含汉字的词写成 `{漢字|かな}`**，读音必须准确（页面会渲染成注音）。题目的 `q` 和 `options` 不加标记。
2. 每道选择题都要有 `explain`（依据）、`why`（数组，长度等于选项数，逐个说明对错，正确的那个以「✓」开头）、`point`（一句要点）。`answer` 是从 0 开始的下标。
3. 改了台词或例句的文字，旧的配音就对不上了：要么只改中文/讲解，要么在提交说明里写清楚“改了日语原文”，作者那边会重新配音。
4. 「日本の歌」**不收录歌词原文和音频**（版权），只放官方播放链接和逐段的单词、语法讲解。
5. 「大人の会話」默认隐藏，页面底部勾选后才显示。

## 同步方式

作者电脑上有一份源文件，每天晚上自动生成第二天的教材并推到这里。推之前会先拉取本仓库：在这里改过的 `index.html`、`songs/index.json`、`packs/*.json` 会被拿回源文件，不会被覆盖。请直接提交到 `main` 分支（或开 PR）。

## 学习记录与练习体验（2026-10-25）

- 四项学习路线显示所选教材的进度；听力技巧默认折叠，完成该段题目后展开。
- `n2progress` v2 将教材进度存于 `materials[教材日期]`，实际学习日期的统计仍存于 `days[学习日期]`。旧版数据自动迁移并保留；旧版已经混用的答题记录无法反推出真正所属教材，按原记录日期保留，不伪造修复。
- 答题同时保留对错与所选选项，重新进入时能查看原来的错误选择。
- 听力完整播放结束后停止计时；单句听力也计时。切换教材会停止播放、退出旧关卡。
- 错题支持随机最多十题集中复习，不因答错三题而提前结束。成绩面板区分已作答和未作答数量。
- 「备份记录」导出 JSON；「恢复备份」合并进度和错题，不自动跨设备同步。不要清理浏览器数据前忘记备份。
- 顶部日期是暂定备考目标，以官方考试公告为准。教材是原创题型练习，不标作历年真题。
- 回归检查：`node tools/ui-check.js`；教材检查仍用 `node tools/check.js packs/<日期>.json`。
