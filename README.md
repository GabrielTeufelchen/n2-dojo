# N2 道場

JLPT N2（2027-07-04）每日学习网页：听力、读解、单词语法（带アクセント）、跟读、真题题型闯关、文化、日本の歌。

网页：https://gabrielteufelchen.github.io/n2-dojo/

## 文件结构

| 路径 | 内容 | 可以改吗 |
|---|---|---|
| `index.html` | 整个网页（样式 + 脚本）。头尾的 `<!doctype>…<body>` 外壳是同步脚本自动加的，别删 | 可以 |
| `packs/<日期>.json` | 每天一套教材 | 可以（改错字、补讲解） |
| `packs/index.json` | 教材日期列表 | 新增教材时要同步加日期 |
| `songs/index.json` | 「日本の歌」栏目 | 可以 |
| `audio/<日期>/day-*.mp4` + `index.json` | VOICEVOX 配音（整天一个文件，index.json 记每句的起止秒数和语调） | **不要改**，由作者电脑上的 VOICEVOX 生成 |
| `tools/DAILY.md` | 教材的完整内容规范（字段、题型轮换、讲解要求） | 参考 |
| `tools/check.js` | 教材检查：`node tools/check.js packs/2026-10-25.json` | 参考 |

## 改内容的规则

1. **日语正文里每个含汉字的词写成 `{漢字|かな}`**，读音必须准确（页面会渲染成注音）。题目的 `q` 和 `options` 不加标记。
2. 每道选择题都要有 `explain`（依据）、`why`（数组，长度等于选项数，逐个说明对错，正确的那个以「✓」开头）、`point`（一句要点）。`answer` 是从 0 开始的下标。
3. 改了台词或例句的文字，旧的配音就对不上了：要么只改中文/讲解，要么在提交说明里写清楚“改了日语原文”，作者那边会重新配音。
4. 「日本の歌」可将学习者提供的歌词段落转化为带读音、翻译和练习的逐句课；不抓取额外完整歌词，不托管原唱文件。使用准确标注版本的官方播放器，并支持本地音频 A–B 复读（文件不上传、刷新后需重新选择）。歌曲学习与测验进度纳入学习记录备份。
5. 「大人の会話」默认隐藏，页面底部勾选后才显示。

## 同步方式

作者电脑上有一份源文件，每天晚上自动生成第二天的教材并推到这里。推之前会先拉取本仓库：在这里改过的 `index.html`、`songs/index.json`、`packs/*.json` 会被拿回源文件，不会被覆盖。请直接提交到 `main` 分支（或开 PR）。

## 学习记录与练习体验（2026-10-25）

- 四项学习路线显示所选教材的进度；听力技巧默认折叠，完成该段题目后展开。
- `n2progress` v2 将教材进度存于 `materials[教材日期]`，实际学习日期的统计仍存于 `days[学习日期]`。旧版数据自动迁移并保留；旧版已经混用的答题记录无法反推出真正所属教材，按原记录日期保留，不伪造修复。
- 答题同时保留对错与所选选项，重新进入时能查看原来的错误选择。
- 听力完整播放结束后停止计时；单句听力也计时。切换教材会停止播放、退出旧关卡。
- 错题支持随机最多十题集中复习，不因答错三题而提前结束。成绩面板区分已作答和未作答数量。
- 「备份记录」导出 JSON；「恢复备份」合并进度和错题，不自动跨设备同步。不要清理浏览器数据前忘记备份。
- 顶部日期是暂定备考目标，以官方考试公告为准。教材是原创题型练习，不标作历年真题。
- 回归检查：`node tools/ui-check.js`；教材检查仍用 `node tools/check.js packs/<日期>.json`。

## 每日一首歌曲课（2026-10-26）

- `songs/index.json` 中每首歌曲须有唯一的 `date`（上海日期 YYYY-MM-DD）与 `id`。每天新增一首不同的歌，不能仅轮换旧歌或只有播放入口。
- 跟随顶部教材日期进入当天推荐；保存的往期选择按日期隔离，新的一天不会停留在昨天的歌。当天缺课时明确显示尚未发布，不伪装成已更新。
- 每课包含准确标注版本的官方页内播放器、学习目标、听辨任务、至少 6 个教学单元、至少 6 道带解析的检测题。每道新题有 explain / why / point；所有教学句的汉字须标读音。
- 用户提供的歌词可做逐句课；未提供的歌曲用语义概述、词汇与原创迁移例句教学，不编造歌词，也不复制额外整首歌词。原创句必须明确标注，不与歌词混淆。
- 保留旧课和稳定的题目顺序，学习进度按歌曲 ID 隔离。每日工作先检查目标日期，已完成则不重复发布。

- **有几天教材，就必须有几首不同的歌**：每次发布读取 `packs/index.json` 全量核对日期（包括提前准备的教材），补齐所有缺课，不能只检查当天。`node tools/song-check.js` 会检查日期覆盖和音源不重复。

- 额外提供歌词时可新增 `supplemental: true` 的补充课（独立歌曲 ID 和进度），日期表示加入日期；它不替换当天推荐，也不计入每日覆盖数。在歌曲菜单中标为“补充歌词课”。

## 每日进阶（2026-10-27 新增）

- 用户要求只做加法。原 packs、教材配音、周主题与旧题顺序不变；新增 `grammar-path.json`，页面“每日进阶”入口为独立路线。
- 每天20分钟（新课15＋间隔复习5），计入原有词汇语法30分钟；剩余10分钟词汇，不增加每天2小时总量。
- 每周6个不同的新语法＋1天混合复习。新语法按功能轮换，不连续一周只学使役受身；D+1、D+3、D+7复习旧课。复习日引用稳定lesson ID，不能复制新ID伪装新内容。
- JSON 中 `lessons` 按日期升序，日期/id唯一。新课包含 meaning、form、note、2个带汉字读音的examples、2道有explain/why/point的quiz；复习课包含有效reviewIds。解释简短，避免冗长中文标签。
- `roadmap` 是到2027年7月的阶段计划，不表示未来所有课程已经编写。只把实际存在且完整的课程显示为已备好；缺当天课必须明确提示。
- 每日检查未来至少7天覆盖，按roadmap补新课；只追加，不改已发布课程ID、日期、题目顺序。先看过去已教内容，避免把复习点当新课。
- 进阶答题在 `progress.grammarPath[lessonId]` 单独保存，纳入备份/恢复。错题进入原错题本；Retry只重做当前进阶课。
- 检查：`node tools/ui-check.js`、`node tools/grammar-path-check.js`、`node tools/song-check.js`。发布前确认原 packs/audio 无改动。
