アイネクライネ

米津玄師 · 2026-10-24

以人与人之间的相遇、感谢和不安为切入点，复习授受表达，并练习「おかげで」「せいで」「ように」。

学习目标

  • 分清「くれる」和「もらう」的视点
  • 用「おかげで」「せいで」说明影响
  • 区分愿望、目的和避免某事

听辨

  • 先观看官方 MV，注意画面如何帮助你理解人物的关系，不急着逐句翻译。
  • 第二遍挑一个你能听清的句尾，留意否定音ない是否完整出现，避免漏掉导致意思相反。
  • 第三遍听完，用本课的授受句描述一件别人帮助你的事；练习的是你自己的表达。

本课主题词汇

用这些词描述听歌的感受；下面的练习句均为原创，不是歌曲原文。

  • 支（ささ）える　支持、支撑。
  • 感謝（かんしゃ）　感谢。
  • 約束（やくそく）　约定。
  • 不安（ふあん）　不安，な形容词或名词。

语法

  • 别人为我或我方做某事，用てくれる，从接受好意的一方叙述。
  • てもらう句子的主语通常是受益者；帮助者用に等标记。
  • おかげで通常把积极结果归功于某个原因；名词后用の。
  • せいで通常说明负面结果的原因；与おかげで的感情色彩不同。
  • 句末ますように常用于祈愿，不是断言愿望已经实现。
  • ない形＋ように表示为了不发生某事而采取措施；ておく强调事先准备。

逐句学习

歌曲关联学习 · 以下 6 句均为原创练习句，不是歌词。

友達（ともだち）が最後（さいご）まで話（はなし）を聞（き）いてくれた。

朋友一直听我说到了最后。

友達が是做动作的人；話を聞く＝听人说话；てくれた＝对我做了有益的事。

别人为我或我方做某事，用てくれる，从接受好意的一方叙述。

用てくれた说一件最近别人帮你的事。

先生（せんせい）に作文（さくぶん）を直（なお）してもらった。

请老师帮我修改了作文。

先生に标记帮助者；直す＝修改；てもらった＝得到了对方的帮助。

てもらう句子的主语通常是受益者；帮助者用に等标记。

与先生が直してくれた比较，同一件事的叙述视点不同。

支（ささ）えてくれた人（ひと）のおかげで、続（つづ）けられた。

多亏支持我的人，我才能坚持下来。

支えてくれた修饰人；人のおかげで＝多亏那个人；続けられた＝能够继续。

おかげで通常把积极结果归功于某个原因；名词后用の。

说一件受到帮助后做到的事，用おかげで。

寝不足（ねぶそく）のせいで、集中（しゅうちゅう）できなかった。

因为睡眠不足，没法集中精神。

寝不足＝缺觉；せいで＝因为……而造成不好的结果；集中できない＝无法专心。

せいで通常说明负面结果的原因；与おかげで的感情色彩不同。

分别用寝不足のせいで和十分寝たおかげで说两句。

大切（たいせつ）な人（ひと）が元気（げんき）でいられますように。

愿重要的人一直平安健康。

大切な人＝重要的人；元気でいる＝保持健康；いられる＝能够保持；ますように＝祝愿。

句末ますように常用于祈愿，不是断言愿望已经实现。

给朋友写一句祝愿，结尾用ますように。

約束（やくそく）を忘（わす）れないように、手帳（てちょう）に書（か）いておく。

为了不忘记约定，提前记在记事本上。

忘れないように＝为避免忘记；手帳に＝记在本上；書いておく＝提前写好。

ない形＋ように表示为了不发生某事而采取措施；ておく强调事先准备。

把约定换成词汇复习，写一个你会采取的防忘措施。

检测题

1. 「友達が手伝ってくれた」是谁帮助了谁？

  1. 我帮助了朋友。
  2. 朋友帮助了我或我方。
  3. 我被迫帮助朋友。
  4. 朋友禁止我帮助。

答案 2　が前面是帮助者，くれる朝向我或我方。

  • 这是てあげる等视点的表达。
  • ✓ が前面是帮助者，くれる朝向我或我方。
  • 没有使役被动。
  • 没有禁止。

别人为我或我方做某事，用てくれる，从接受好意的一方叙述。

2. 「先生に教えてもらった」中，先生是？

  1. 接受教导的人。
  2. 提供教导的人。
  3. 被说明的物品。
  4. 上课的时间。

答案 2　に标记实施教导的人。

  • 接受教导的是省略的我等受益者。
  • ✓ に标记实施教导的人。
  • 先生是人，不是物品。
  • 不是时间。

てもらう句子的主语通常是受益者；帮助者用に等标记。

3. 「先生のおかげで合格できた」表达？

  1. 责怪老师。
  2. 感谢老师带来的帮助。
  3. 否认老师存在。
  4. 要求老师再考试。

答案 2　おかげで把成功归功于老师的帮助。

  • 积极结果通常不是责怪。
  • ✓ おかげで把成功归功于老师的帮助。
  • 没有否认。
  • 没有要求老师考试。

おかげで通常把积极结果归功于某个原因；名词后用の。

4. 「雨のせいで試合が中止になった」中，せいで主要表达？

  1. 积极的感谢。
  2. 导致不良结果的原因。
  3. 与此同时。
  4. 即使如此。

答案 2　せいで将取消归因于雨。

  • 感谢多用おかげで。
  • ✓ せいで将取消归因于雨。
  • 同时动作常用ながら。
  • 让步常用ても。

せいで通常说明负面结果的原因；与おかげで的感情色彩不同。

5. 「元気でいられますように」是在？

  1. 陈述已经痊愈。
  2. 表达祝愿。
  3. 要求对方立刻跑步。
  4. 否定健康的重要。

答案 2　句末ように表达愿望或祈愿。

  • 不是既成事实。
  • ✓ 句末ように表达愿望或祈愿。
  • 没有这个命令。
  • 没有否定。

句末ますように常用于祈愿，不是断言愿望已经实现。

6. 忘れ（　）ように、メモしておきます。

  1. ない
  2. ます
  3. たかった
  4. よう

答案 1　忘れないように，表示为了不忘。

  • ✓ 忘れないように，表示为了不忘。
  • ます不能这样直接接ように。
  • 过去想忘不符合防忘的目的。
  • 重复よう不成立。

ない形＋ように表示为了不发生某事而采取措施；ておく强调事先准备。
