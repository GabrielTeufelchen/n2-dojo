Vocab

回忆与再会

  • 再会（さいかい）　再会
  • 覚（おぼ）える　记住
  • 約束（やくそく）　约定

语法

  • たことがある：经历
  • たものだ：回忆习惯
  • たまま：保持状态
  • ようとする：试图
  • ことにする：主动决定
  • だけでなく：不但

逐句学习

原创迁移练习 · 以下6句不是歌词。

子供（こども）のころ、この公園（こうえん）で遊（あそ）んだことがある。

小时候，我曾在这个公园玩过。

子供のころ＝小时候；遊ぶ＝玩。

たことがある：有过某种经历，不表示经常做。

よく遊んだ＝经常玩。

夏休（なつやす）みには、暗（くら）くなるまで外（そと）で遊（あそ）んだものだ。

暑假时，我们常常在外面玩到天黑啊。

暗くなるまで＝直到天黑。

たものだ：带感慨回顾过去反复做的事。

たことがある只表示曾经做过。

昔（むかし）の写真（しゃしん）を見（み）たまま、しばらく動（うご）けなかった。

看着旧照片，我一时愣住，动弹不得。

見たまま＝保持看后的状态；動けない＝不能动。

たまま：状态未改变；动不了用可能形否定。

立ったまま＝保持站立。

別（わか）れ際（ぎわ）に、何（なに）か伝（つた）えようとした。

临别时，我试图说些什么。

別れ際＝临别之际；伝える＝传达。

意向形＋とする：试图做；不保证做成。

伝える→伝えよう。

来年（らいねん）も同（おな）じ場所（ばしょ）で会（あ）うことにした。

我们决定明年也在同一个地方见面。

同じ場所＝同一地点。

ことにした：主动作出决定。

ことになった：事情被安排、决定下来。

楽（たの）しかったことだけでなく、失敗（しっぱい）したことも覚（おぼ）えている。

不但记得开心的事，也记得失败的事。

覚えている＝记得；失敗する＝失败。

だけでなく〜も：不但……也……。

名词化的こと可指具体事情。

检测题

1. 「遊んだことがある」は？

  1. 曾经玩过
  2. 每天都玩
  3. 必须玩
  4. 从未玩过

答案 1　表示经历。

  • ✓ 表示经历。
  • 不保证频率。
  • 没有义务。
  • 不是否定。

たことがある：曾经。

2. 「よく遊んだものだ」は？

  1. 将来计划
  2. 感慨过去常玩
  3. 只玩一次
  4. 禁止玩

答案 2　回忆过去习惯。

  • 不是将来。
  • ✓ 回忆过去习惯。
  • よく表示经常。
  • 不是禁止。

たものだ：回忆过去常做。

3. 「立ったまま」は？

  1. 站起来之前
  2. 从未站过
  3. 保持站立状态
  4. 只想站起来

答案 3　状态持续。

  • 不是之前。
  • 不是经历。
  • ✓ 状态持续。
  • 不是愿望。

たまま：状态不变。

4. 「伝えようとした」は？

  1. 已经传达很久
  2. 被迫传达
  3. 不能传达
  4. 试图传达

答案 4　意向形＋とする。

  • 不是持续。
  • 没有被迫。
  • 不是能力否定。
  • ✓ 意向形＋とする。

ようとする：试图。

5. 「会うことにした」は？

  1. 决定见面
  2. 从未见过
  3. 碰巧见过
  4. 不许见面

答案 1　主动作决定。

  • ✓ 主动作决定。
  • 不是经历否定。
  • 不是偶然经历。
  • 没有禁止。

ことにする：主动决定。

6. 「楽しいことだけでなく、失敗も」は？

  1. 只有开心事
  2. 两种事情都包括
  3. 两者都排除
  4. 只包括失败

答案 2　不但前者也有后者。

  • だけでなく扩大范围。
  • ✓ 不但前者也有后者。
  • 不是全面否定。
  • 也有前者。

だけでなく〜も：不但……也……。
