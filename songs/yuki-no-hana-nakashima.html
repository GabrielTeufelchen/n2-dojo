中島美嘉 · 雪の華 · 官方原曲 Music Video

中島美嘉《雪の華》（2003）。播放器为本人官方频道发布的原曲Music Video。围绕冬日与陪伴练习；下方6句均为原创迁移例句，不是歌词。

学习目标

  • 听辨舒缓歌声中的元音延长与词界
  • 区分降りそう的迹象与降るそう的传闻
  • 用につれて和うちに描述变化

听辨

  • 第一遍完整听，留意主歌到副歌的力度变化。
  • 第二遍回听5～10秒，分辨哪些元音被拖长；用手打拍子，不额外添加音节。
  • 第三遍先说后唱同一短段，再用下方原创句描述天气与心情。

Vocab

冬日与陪伴

  • 指先（ゆびさき）　指尖
  • 冷（つめ）たい　冰冷的
  • 相手（あいて）　对方

语法

  • につれて：相伴变化
  • せいで：不利原因
  • そうだ：迹象与传闻
  • うちに：过程中变化
  • だけで：仅凭
  • ないことには：必要条件

逐句学习

原创迁移练习 · 以下6句不是歌词。

冬（ふゆ）が近（ちか）づくにつれて、日（ひ）が短（みじか）くなってきた。

随着冬天临近，白天逐渐变短了。

日が短い＝白昼短。

につれて：相伴变化；てくる：变化延续到现在。

近づく＋につれて。

冷（つめ）たい風（かぜ）のせいで、指先（ゆびさき）が痛（いた）くなった。

因为冷风，指尖疼了起来。

指先＝指尖。

せいで：将不好的结果归因于前项。

冷たい風＋のせいで。

雪（ゆき）が降（ふ）りそうなので、早（はや）めに家（いえ）を出（で）よう。

看起来要下雪，我们早点出门吧。

早めに＝提早一些。

ます形去ます＋そうだ：根据迹象判断将要发生。

降りそう：看来要下；降るそう：听说会下。

二人（ふたり）で歩（ある）いているうちに、寒（さむ）さを忘（わす）れていた。

两个人走着走着，不知不觉忘记了寒冷。

寒さ＝寒冷。

ているうちに：持续过程中自然发生变化。

忘れていた：当时已处于忘却的状态。

大切（たいせつ）な人（ひと）と過（す）ごせるだけで、十分（じゅうぶん）幸（しあわ）せだ。

只要能和重要的人一起度过时光，就已经足够幸福。

過ごせる＝能度过。

だけで：仅凭这一条件就足够。

過ごす→過ごせる。

相手（あいて）の話（はなし）を聞（き）かないことには、気持（きも）ちは分（わ）からない。

不听对方说，就无法了解对方的心情。

相手＝对方。

ないことには～ない：不先做前项，就无法做后项。

聞かないことには＝不先听的话。

检测题

1. 「冬が近づくにつれて、日が短くなる」は？

  1. 冬天近了但白昼不变
  2. 两种变化相伴发生
  3. 为了缩短白天而入冬
  4. 听说白天变短

答案 2　前后变化相伴。

  • 明确发生变化。
  • ✓ 前后变化相伴。
  • 不是目的。
  • 没有传闻。

につれて：随变化。

2. 「冷たい風のせいで」は？

  1. 多亏温暖的风
  2. 为了吹风
  3. 因为冷风造成坏结果
  4. 即使无风

答案 3　用于不好的结果。

  • せいで归因于不利因素。
  • 不是目的。
  • ✓ 用于不好的结果。
  • 不是让步。

名词＋のせいで。

3. 看天空觉得快下雪，应说？

  1. 雪が降るそうだ
  2. 雪が降ったそうだ
  3. 雪を降らせる
  4. 雪が降りそうだ

答案 4　ます形词干＋そう表示迹象。

  • 辞书形＋そう是传闻。
  • 过去形＋そう也是传闻。
  • 使役，表示使下雪。
  • ✓ ます形词干＋そう表示迹象。

降りそう≠降るそう。

4. 「歩いているうちに、寒さを忘れた」は？

  1. 走着走着忘了寒冷
  2. 走之前先忘记
  3. 为了忘记所以没走
  4. 走完才决定忘记

答案 1　动作持续中产生变化。

  • ✓ 动作持续中产生变化。
  • 不是之前。
  • 没有否定走路。
  • 不是决定。

ているうちに：过程中变化。

5. 「一緒に過ごせるだけで幸せだ」は？

  1. 只能分开才幸福
  2. 必须买礼物才幸福
  3. 仅仅能一起度过就幸福
  4. 完全不幸福

答案 3　だけで说明这一条件已经足够。

  • 不是分开。
  • 没有礼物条件。
  • ✓ だけで说明这一条件已经足够。
  • 没有否定。

だけで：仅凭。

6. 話を聞かないことには、気持ちは（　）。

  1. 分かる一方だ
  2. 分からない
  3. 分かってよかった
  4. 分かりそうにする

答案 2　前项不成立，后项就无法成立。

  • 与必要条件不合。
  • ✓ 前项不成立，后项就无法成立。
  • 不是已经了解。
  • 接续和意思都不合。

ないことには～ない。
