Vocab

友情与支持

  • 友情（ゆうじょう）　友情
  • 遠慮（えんりょ）　客气、顾虑
  • 安心（あんしん）　安心

语法

  • てくれる：受惠
  • なくても／だけで：让步与条件
  • とは限らない：未必
  • せずに／てほしい：不做与希望
  • ようになる：变化
  • ばかりでなく：不仅

逐句学习

原创迁移练习 · 以下6句不是歌词。

友達（ともだち）が話（はなし）を聞（き）いてくれたおかげで、気持（きも）ちが楽（らく）になった。

多亏朋友听我倾诉，我心里轻松了。

気持ちが楽になる＝心情轻松起来。

てくれる：他人为我做；おかげで：有利原因。

聞いてくれた＋おかげで。

何（なに）も言（い）わなくても、そばにいてくれるだけで安心（あんしん）する。

即使什么也不说，只要陪在身边就让我安心。

そばにいる＝在身边。

なくても：即使不做；だけで：仅凭。

言わない→言わなくても。

親（した）しい友達（ともだち）でも、考（かんが）え方（かた）が同（おな）じとは限（かぎ）らない。

即使是亲密朋友，想法也不一定相同。

考え方＝思考方式。

とは限らない：不能一概断定。

不是断言一定不同。

困（こま）ったときは、遠慮（えんりょ）せずに連絡（れんらく）してほしい。

遇到困难时，希望你别客气，联系我。

遠慮する＝客气、顾虑。

せずに：不做；てほしい：希望他人做。

する→せずに。

離（はな）れて暮（く）らすようになってから、友情（ゆうじょう）の大切（たいせつ）さに気（き）づいた。

分开生活之后，我才意识到友情的可贵。

気づく＝意识到，内容接に。

ようになる：变化；てから：之后。

暮らす＝生活。

助（たす）けてもらうばかりでなく、自分（じぶん）にもできることを探（さが）したい。

我希望不只接受帮助，也寻找自己能做的事。

助けてもらう＝得到帮助。

ばかりでなく：不仅……还……。

自分にもできる＝自己也能做到。

检测题

1. 「話を聞いてくれた」は？

  1. 我替别人说话
  2. 别人听我倾诉
  3. 我被禁止听
  4. 别人让我闭嘴

答案 2　くれる表示他人为我做。

  • 动作主体是朋友。
  • ✓ くれる表示他人为我做。
  • 没有禁止。
  • 不是使役。

てくれる：他人为我做。

2. 「そばにいてくれるだけで安心する」は？

  1. 必须一直说话
  2. 只有离开才安心
  3. 仅陪在身边就安心
  4. 完全无法安心

答案 3　だけで表示这一条件已足够。

  • 何も言わなくても否定此要求。
  • 不是离开。
  • ✓ だけで表示这一条件已足够。
  • 安心する是肯定。

だけで：仅凭。

3. 「友達でも考え方が同じとは限らない」は？

  1. 朋友想法一定相反
  2. 朋友必定想法相同
  3. 不能交朋友
  4. 朋友想法未必相同

答案 4　保留相同或不同的可能。

  • 不一定相同不等于一定相反。
  • 否定这种绝对判断。
  • 没有禁止。
  • ✓ 保留相同或不同的可能。

とは限らない：未必。

4. 遠慮する的「不客气地」是？

  1. 遠慮せずに
  2. 遠慮しずに
  3. 遠慮するずに
  4. 遠慮すずに

答案 1　する→せずに。

  • ✓ する→せずに。
  • する是特殊变化。
  • ずに不直接接辞书形。
  • 该形式不成立。

する→せずに。

5. 「離れて暮らすようになった」は？

  1. 已经不住了
  2. 被迫住在一起
  3. 生活状态变成分开居住
  4. 希望一起住

答案 3　ようになる表示状态变化。

  • 不是否定居住。
  • 不是使役受身。
  • ✓ ようになる表示状态变化。
  • 不是愿望。

ようになる：状态或习惯变化。

6. 「助けてもらうばかりでなく」は？

  1. 只接受帮助
  2. 不仅接受帮助
  3. 拒绝所有帮助
  4. 因为不能帮助

答案 2　后项补充另一件事。

  • ばかりでなく否定只限于此。
  • ✓ 后项补充另一件事。
  • 不是全面拒绝。
  • 不是原因。

ばかりでなく：不仅。
