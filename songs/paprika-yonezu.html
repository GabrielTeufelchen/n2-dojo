パプリカ

米津玄師 · 2026-11-24

听米津玄師自唱版，再用重访旧公园的小故事练习讲回忆。

学习目标

  • 听出歌名的四拍
  • 用ぶりに说出重访间隔
  • 区分实际经历与主观印象

听辨

  • 听到歌名时轻敲四拍：パ・プ・リ・カ。
  • 再听一次，留意唱完「カ」后人声有没有停顿，模仿一次。
  • 选副歌末尾的一小句，听两遍，哼出最后一个音的走向。

米津玄師 · パプリカ · 作者自唱版官方 MV

Vocab

重访与回忆

  • 笑（わら）い声（ごえ）　笑声
  • 記念（きねん）　纪念
  • あの頃（ころ）　那时候

语法

  • 时间段＋ぶりに＋动作。
  • 名词＋のまま表示状态延续。
  • 気がした保留了“感觉如此”的语气。
  • 辞书形＋前に，后面的动作先发生。
  • たら接已发生的事，可以引出随后出现的结果。
  • 意向形＋ということになった，转述商量出来的安排。

逐句学习

原创迁移练习 · 以下六句不是歌词。

昔（むかし）よく遊（あそ）んだ公園（こうえん）を、十年（じゅうねん）ぶりに訪（おとず）れた。

时隔十年，我又去了小时候常玩的公园。

十年ぶりに＝隔了十年再一次。

时间段＋ぶりに＋动作。

把十年换成半年。

ブランコは古（ふる）くなっていたが、ベンチはあの頃（ころ）のままだった。

秋千已经旧了，长椅还和那时候一样。

あの頃のまま＝保持当时的样子。

名词＋のまま表示状态延续。

哪个东西一直没变？

目（め）を閉（と）じると、友達（ともだち）の笑（わら）い声（ごえ）が聞（き）こえる気（き）がした。

闭上眼，我仿佛听见了朋友的笑声。

聞こえる＝声音传入耳中。

気がした保留了“感觉如此”的语气。

确定真的有人在笑吗？

帰（かえ）る前（まえ）に、記念（きねん）に写真（しゃしん）を一枚（いちまい）撮（と）った。

回去前，我拍了一张照片留念。

記念に＝为了留念。

辞书形＋前に，后面的动作先发生。

先拍照还是先回家？

写真（しゃしん）を送（おく）ったら、すぐに返事（へんじ）が来（き）た。

照片发过去，很快便收到了回复。

返事が来る＝收到回复。

たら接已发生的事，可以引出随后出现的结果。

把回复换成电话。

今度（こんど）は二人（ふたり）で行（い）こうということになった。

我们商量好，下次两个人一起去。

二人で＝两个人一起。

意向形＋ということになった，转述商量出来的安排。

把去公园换成去看电影。

检测题

1. 十年ぶりに公園を訪れた。这个人上次什么时候来过？

  1. 十年前
  2. 十天前
  3. 每年都来
  4. 第一次来

答案 1　十年ぶり指两次到访之间的时间。

  • ✓ 两次到访相隔十年。
  • 年和天的单位不同。
  • 每年都来就没有十年的间隔。
  • ぶり暗含以前有过。

半年ぶり＝时隔半年。

2. 「ベンチはあの頃のままだった。」长椅怎么样了？

  1. 换了位置
  2. 跟以前一样
  3. 刚装好
  4. 被拆了

答案 2　あの頃のまま把眼前的长椅与记忆里的长椅连起来。

  • 没有提搬动。
  • ✓ 原来的状态延续下来。
  • 刚装好不能体现延续。
  • 长椅还在。

名词后接のまま。

3. 「笑い声が聞こえる気がした。」能确定什么？

  1. 朋友在场
  2. 听者笑了
  3. 听者觉得听到了笑声
  4. 朋友在打电话

答案 3　句尾把听到笑声写成一种印象。

  • 只说了感觉。
  • 声音属于回忆里的朋友。
  • ✓ 気がした是个人感受。
  • 没提电话。

读到句尾再判断确定程度。

4. 帰る前に写真を撮った。哪个动作在先？

  1. 回家
  2. 打印照片
  3. 回复
  4. 拍照

答案 4　帰る是前に标出的时间界限。

  • 帰る前＝还没回去时。
  • 没说打印。
  • 没说回复。
  • ✓ 先拍照再回家。

A前にB＝先B后A。

5. 「写真を送ったら、返事が来た。」这里的たら最贴近哪种意思？

  1. 如果将来发
  2. 发过去之后
  3. 虽然没发
  4. 为了发送

答案 2　后半句叙述实际收到的回复。

  • 来た说明已有结果。
  • ✓ 两件事先后发生。
  • 送った表示已发。
  • 没有表示目的。

结合后句时态判断。

6. 「二人で行こうということになった。」两人现在怎样了？

  1. 已经到达
  2. 决定各自去
  3. 商量好一起去
  4. 拒绝见面

答案 3　行こう保留了提议的内容。

  • 只是安排。
  • 二人で说明同行。
  • ✓ 共同安排已经定下。
  • 行こう是提议去。

ということになった交代商量结果。
