学习目标

  • 听辨舒缓旋律中的长音和句末
  • 用授受表达描述陪伴与帮助
  • 结合今日进阶区分かねない与普通可能性

听辨

  • 第一遍完整听，留意主歌到副歌的音量与情绪变化。
  • 第二遍选择听清的5～10秒，区分长音、助词和停顿。
  • 第三遍先按说话速度模仿同一短段，再跟唱；用原创句练习关心与约定。

Vocab

陪伴与约定

  • 約束（やくそく）　约定
  • 支（ささ）える　支持
  • 安心（あんしん）　安心

语法

  • てくれる：别人为我做
  • てあげる：为别人做
  • てほしい：希望别人做
  • かねない：有不良可能
  • ないように：为避免
  • おかげで：多亏

逐句学习

原创迁移练习 · 以下6句不是歌词。

友達（ともだち）が話（はなし）を聞（き）いてくれて、安心（あんしん）した。

朋友听我倾诉，我安心了。

話を聞く＝听人倾诉；安心する＝安心。

てくれる：从接受好意的一方描述动作。

母が手伝ってくれた＝妈妈帮了我。

困（こま）っている友達（ともだち）を、できるだけ支（ささ）えてあげたい。

我想尽可能支持遇到困难的朋友。

困っている＝正为难；できるだけ＝尽可能。

てあげる：为别人做；直接向长辈说可能显得居高临下。

支えてくれる：别人支持我。

無理（むり）をしないで、少（すこ）し休（やす）んでほしい。

希望你别勉强自己，稍微休息一下。

無理をする＝勉强自己；休む＝休息。

てほしい：希望对方做某事。

休みたい＝自己想休息。

寝不足（ねぶそく）が続（つづ）くと、体調（たいちょう）を崩（くず）しかねない。

持续睡眠不足，可能会搞坏身体。

寝不足＝睡眠不足；体調を崩す＝身体不适。

ます形词干＋かねない：担心不良结果发生。

崩します→崩しかねない。

約束（やくそく）を忘（わす）れないように、カレンダーに書（か）いておいた。

为免忘记约定，我事先记在日历上。

忘れないように＝为免忘记；書いておく＝提前记下。

ないように：避免某情况；ておく：预先准备。

遅れないように＝为免迟到。

そばにいてくれたおかげで、一人（ひとり）ではないと思（おも）えた。

多亏你陪在身边，我才觉得自己并不孤单。

そばにいる＝在身边；思えた＝能这样想了。

おかげで：把好结果归功于前项。

思った＝这样想了；思えた＝能够这样想。

检测题

1. 「友達が聞いてくれた」は？

  1. 朋友听我倾诉
  2. 我替朋友听
  3. 朋友被禁止听
  4. 我没有听

答案 1　朋友为我做。

  • ✓ 朋友为我做。
  • 方向相反。
  • 没有禁止。
  • 不是我的否定。

てくれる：别人为我做。

2. 「支えてあげたい」は？

  1. 想被帮助
  2. 想支持对方
  3. 已经放弃
  4. 必须道歉

答案 2　说话人想为对方做。

  • 被支持可用支えてもらいたい。
  • ✓ 说话人想为对方做。
  • 没有放弃。
  • 没有道歉。

てあげたい：想为别人做。

3. 「休んでほしい」は？

  1. 自己想休息
  2. 刚休息完
  3. 希望对方休息
  4. 不允许休息

答案 3　希望别人做。

  • 自己想做用たい。
  • 不是过去完成。
  • ✓ 希望别人做。
  • 不是禁止。

てほしい：希望别人做。

4. 体調を崩し（　）。

  1. がたいで
  2. ことなく
  3. つつが
  4. かねない

答案 4　有健康恶化的风险。

  • 接续不合。
  • 此处接续不合。
  • 接续不合。
  • ✓ 有健康恶化的风险。

かねない：不良结果的可能。

5. 「忘れないように書いた」の目的は？

  1. 避免忘记
  2. 为了忘记
  3. 拒绝记录
  4. 已经忘了

答案 1　ないように表示避免。

  • ✓ ないように表示避免。
  • 与否定相反。
  • 已经记录。
  • 没有断言忘了。

ないように：为避免。

6. 「いてくれたおかげで」は？

  1. 责怪对方在场
  2. 感谢对方陪伴带来的好结果
  3. 禁止对方留下
  4. 要求对方离开

答案 2　おかげで用于好结果。

  • 此处是感谢。
  • ✓ おかげで用于好结果。
  • 没有禁止。
  • 没有要求离开。

おかげで：多亏。
