全力少年（ぜんりょくしょうねん）

スキマスイッチ · 2026-11-20

从这首快节奏的歌走进一场比赛：练习描述紧张、坚持和差点实现的目标。

学习目标

  • 听出歌名中「しょう」的长音
  • 区分完成与差一点完成
  • 用一句日语说出下次的决心

听辨

  • 第一遍跟着鼓点轻拍，听到副歌旋律再现时记一次。
  • 第二遍留意歌名的「しょうねん」，听「しょ」后元音持续的位置。
  • 任选一句暂停，用哼唱复现句尾，判断末音是拉长还是迅速收住。

Vocab

比赛与挑战

  • 合図（あいず）　信号
  • 順位（じゅんい）　名次
  • 記録（きろく）　纪录

语法

  • 名词＋のあまり表示程度过强，引出了意外结果。
  • せずに＝しないで。
  • 动词ます形去ます＋きる强调做到底。
  • あと少しで～ところだった表示差点发生。
  • 名词＋はともかく表示暂时搁置一个话题。
  • こそ强调这一次；走ろう表示决心。

逐句学习

原创迁移练习 · 以下六句不是歌词。

最初（さいしょ）の大会（たいかい）では、緊張（きんちょう）のあまりスタートの合図（あいず）を聞（き）き逃（のが）した。

第一场比赛时，我紧张得漏听了起跑信号。

合図を聞き逃す＝漏听信号。

名词＋のあまり表示程度过强，引出了意外结果。

把紧张换成兴奋（興奮）。

次（つぎ）は、順位（じゅんい）を気（き）にせずに走（はし）りたい。

下一场我想抛开名次，好好跑。

順位を気にする＝在意名次。

せずに＝しないで。

用しないで复述。

坂（さか）を上（のぼ）りきったとき、ゴールが見（み）えた。

爬完整个坡时，我看见了终点。

上り＋きる＝一直爬到坡顶。

动词ます形去ます＋きる强调做到底。

说“跑完全程”：最後まで走りきった。

あと少（すこ）しで、チームの記録（きろく）を破（やぶ）るところだった。

我差一点就破了队里的纪录。

記録を破る＝打破纪录。

あと少しで～ところだった表示差点发生。

最后破纪录了吗？

結果（けっか）はともかく、最後（さいご）まで走（はし）れたのがうれしい。

成绩先放一边，能跑到最后我就很高兴。

最後まで走れた＝成功跑到了最后。

名词＋はともかく表示暂时搁置一个话题。

说话人现在最在意哪件事？

今度（こんど）こそ、自分（じぶん）のペースで走（はし）ろう。

下一次，我一定要按自己的节奏跑。

自分のペースで＝按自己的节奏。

こそ强调这一次；走ろう表示决心。

换成“今年一定要参加”：今年こそ参加しよう。

检测题

1. 緊張のあまり、合図を聞き逃した。发生了什么？

  1. 故意没听
  2. 太紧张而漏听
  3. 听完才紧张
  4. 合图画错了

答案 2　「のあまり」前面是过强的情绪。

  • 没有故意的意思。
  • ✓ 紧张导致漏听。
  • 先紧张，后漏听。
  • 合図指信号。

听清情绪和结果的顺序。

2. 「順位を気にせずに」可以换成哪句？

  1. 順位を気にして
  2. 順位を上げて
  3. 順位を気にしないで
  4. 順位を調べて

答案 3　把する换成せずに，意思是没有做这件事就……。

  • 变成了在意。
  • 表示提高名次。
  • ✓ せずに保留否定。
  • 表示查名次。

する→せずに。

3. 跑者说「坂を上りきった」。这时他在哪里？

  1. 坡顶
  2. 坡脚
  3. 坡中间
  4. 还在起点

答案 1　上りきる包含完成整段上坡的意思。

  • ✓ 已经爬完。
  • 还没开始。
  • 还没爬完。
  • 与完成动作不合。

区分上り始める和上りきる。

4. 「あと少しで記録を破るところだった」说明什么？

  1. 刷新了纪录
  2. 正查纪录
  3. 决定退赛
  4. 差一点破纪录

答案 4　あと少しで把动作放在即将实现的边缘。

  • 这次差一点。
  • 破る是打破。
  • 没有提退赛。
  • ✓ 逼近纪录，最终没破。

读到ところだった再判断结果。

5. 「結果はともかく」之后，最自然的下文是？

  1. 結果とは成績のことだ
  2. 仲間と走れてよかった
  3. 結果をもう一度計算しよう
  4. 順位だけを教えて

答案 2　先放下成绩，再说自己看重的体验。

  • 在给结果下定义。
  • ✓ 转向和伙伴同跑的体验。
  • 又回到计算成绩。
  • 只关心名次。

Aはともかく，重点在后半句。

6. 今度（　）、最後まで走ろう。强调“下次一定”。

  1. ほど
  2. しか
  3. こそ
  4. まで

答案 3　今度こそ带有重新挑战的决心。

  • 表示程度。
  • 通常与否定呼应。
  • ✓ 突出这一次。
  • 表示界限。

こそ紧跟要强调的词。
