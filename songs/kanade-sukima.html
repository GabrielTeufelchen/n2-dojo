Vocab

告别与联络

  • 見送（みおく）る　送行
  • 連絡（れんらく）　联络
  • 思（おも）い出（で）　回忆

语法

  • たびに：每当
  • たとたん：刚一……就
  • て以来：自从
  • ように：为了能
  • ことなく：没有……就
  • ばかりに：只因……造成坏结果

逐句学习

原创迁移练习 · 以下6句不是歌词。

駅（えき）を通（とお）るたびに、友達（ともだち）を見送（みおく）った日（ひ）を思（おも）い出（だ）す。

每次经过车站，都会想起为朋友送行的那天。

見送る＝送行；思い出す＝想起。

たびに：每次前项发生，后项也发生。

通るたびに＝每次经过。

電車（でんしゃ）が出発（しゅっぱつ）したとたん、涙（なみだ）が出（で）た。

列车刚出发，我就流泪了。

出発した＝出发了；涙が出る＝流泪。

たとたん：前项刚发生就出现后项，常带意外感。

出発する前に＝出发之前。

彼（かれ）と別（わか）れて以来（いらい）、毎週（まいしゅう）メールを送（おく）っている。

自从与他分别以后，我每周都发邮件。

別れて以来＝自从分别后。

て以来：从某事件起，一直持续到现在。

別れるたびに＝每次分别时，强调重复。

いつでも連絡（れんらく）できるように、電話番号（でんわばんごう）を交換（こうかん）した。

为了随时能联系，我们交换了电话号码。

連絡できる＝能联系；交換する＝交换。

可能形＋ように：为了达到某种状态。

連絡するために也可表达主动联系的目的。

何（なに）も言（い）うことなく、彼女（かのじょ）は手（て）を振（ふ）った。

她什么也没说，只挥了挥手。

言うことなく＝没有说；手を振る＝挥手。

辞书形＋ことなく：不做某事就做后项，较书面。

何も言わずに意思接近。

出発時間（しゅっぱつじかん）を間違（まちが）えたばかりに、見送（みおく）りに間（ま）に合（あ）わなかった。

只因弄错出发时间，我没赶上送行。

間違える＝弄错；間に合う＝赶得上。

ばかりに：强调某个原因引出遗憾结果。

たばかり＝刚做完，和ばかりに不同。

检测题

1. 「通るたびに」は？

  1. 每次经过
  2. 只经过一次
  3. 经过之前
  4. 从不过去

答案 1　每次发生。

  • ✓ 每次发生。
  • 不是一次。
  • 不是之前。
  • 没有否定。

たびに：每当。

2. 電車が出発し（　）、涙が出た。

  1. ながらを
  2. たとたん
  3. てため
  4. に応じ

答案 2　刚出发就流泪。

  • 接续不合。
  • ✓ 刚出发就流泪。
  • 接续不合。
  • 接续不合。

たとたん：紧接发生。

3. 「別れて以来、メールを送っている」は？

  1. 分别之前发过一次
  2. 每次分别都停发
  3. 分别后一直保持发邮件
  4. 从未分别

答案 3　从分别起持续。

  • 不是之前。
  • 没有停发。
  • ✓ 从分别起持续。
  • 已经分别。

て以来：从过去持续至今。

4. 連絡できる（　）、番号を交換した。

  1. だけにを
  2. ことなくに
  3. ばかりを
  4. ように

答案 4　为了能联系。

  • 接续不合。
  • 接续不合。
  • 接续不合。
  • ✓ 为了能联系。

可能形＋ように。

5. 「言うことなく」は？

  1. 没有说
  2. 刚刚说过
  3. 必须说
  4. 反复说

答案 1　相当于言わずに。

  • ✓ 相当于言わずに。
  • 不是刚做完。
  • 不是义务。
  • 不是重复。

ことなく：没有做。

6. 「間違えたばかりに」は？

  1. 刚刚弄错
  2. 只因弄错而造成坏结果
  3. 总是弄错
  4. 大概没弄错

答案 2　强调遗憾的原因。

  • 刚做完是たばかり。
  • ✓ 强调遗憾的原因。
  • 总是用ばかりいる等。
  • 没有推测否定。

ばかりに：原因与遗憾结果。
