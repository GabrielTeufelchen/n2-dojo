本课主题词汇

补充词汇。原有迁移练习在附加区。

  • 空（そら）　天空。
  • 飛（と）ぶ　飞，可能形是飛べる。
  • 期待（きたい）　期待。
  • 確信（かくしん）　确信；与单纯的可能性区分。

语法

  • 五段动词的可能形把词尾变成え段后加る：飛ぶ → 飛べる。
  • 普通形＋はずだ表示有依据的预期，不是绝对保证。
  • 辞书形＋つもりだ表达个人计划；はずだ表达预期判断。
  • 可能形＋ようになる表示原本不会而逐渐变得能做到。
  • 意志性目标可用辞书形＋ために；后项说为目标采取的行动。
  • かもしれない只保留可能性；其确定程度不能当作はずだ那样的有依据预期来理解。

おさない微熱（びねつ）を下（さ）げられないまま

那稚嫩的微热，依旧无法退去。

おさない＝幼小、稚嫩；微熱＝低烧；下げられない＝无法使其降低；まま＝保持该状态。

下げる的可能形否定＋まま。微热也可读为青春的躁动，是意象解读。

下がらない＝没有降下来；下げられない＝无法使其降低。

神様（かみさま）の影（かげ）を恐（おそ）れて

畏惧着神明的阴影，

神様＝神明；影＝影子；恐れる＝害怕、畏惧。

て形连接后文；恐れる的对象用を。歌词没有明说神影具体指什么。

恐れる→恐れて；怖い＝害怕的。

隠（かく）したナイフが似合（にあ）わない僕（ぼく）を

那把藏起的刀，与我格格不入；这样的我，

隠したナイフ＝藏起的刀；似合わない＝不相称；僕を＝安慰的对象。

［隠したナイフが似合わない］修饰僕；僕を要接下一行なぐさめた。

还原：ナイフが僕に似合わない＝刀与我不相称。

おどけた歌（うた）でなぐさめた

用诙谐的歌，安慰了我。

おどけた＝滑稽、诙谐的；歌で＝用歌；なぐさめた＝安慰了。

で表示手段。动作主体省略，可结合后面的君理解为你；原句是主动式，不是语法上的被动。

僕をなぐさめた＝安慰了我；僕がなぐさめられた＝我被安慰了。

色褪（いろあ）せながら ひび割（わ）れながら

一边褪色，一边出现裂痕，

色褪せる＝褪色；ひび割れる＝出现裂缝；ながら＝一边……。

两个ながら并列，接下一行仍追求发光的方式；语境也有即使受损仍追求的意味。

色褪せる→色褪せながら；ひび割れる→ひび割れながら。

輝（かがや）くすべを求（もと）めて

仍寻求着绽放光芒的办法。

輝く＝闪耀；すべ＝方法、手段；求める＝寻求。

［輝く］修饰すべ。没有比较词，不必加译“更闪烁”；て形让意象延续。

すべ在此是方法，不是すべて“全部”。

君（きみ）と出会（であ）った奇跡（きせき）が この胸（むね）にあふれてる

与你相遇的奇迹，洋溢在我心中。

君と出会った＝与你相遇了；奇跡＝奇迹；胸に＝在心中；あふれてる＝あふれている。

［君と出会った］修饰奇跡，が标主语；ている省略い，表示心中满溢的状态。

奇跡读きせき；不要与軌跡（轨迹）混淆。

きっと今（いま）は自由（じゆう）に空（そら）も飛（と）べるはず

如今，我一定连天空也能自由飞翔。

きっと＝一定；自由に＝自由地；空も＝连天空也；飛べる＝能飞；はず＝应当。

可能形＋はず表达有理由相信的判断；这里以相遇带来的力量写强烈信心。

飛ぶ→飛べる；はず不是法律或道德上的“应该”。

夢（ゆめ）を濡（ぬ）らした涙（なみだ）が 海原（うなばら）へ流（なが）れたら

如果浸湿梦想的泪水，流向辽阔的大海，

夢を濡らした＝浸湿了梦想的；涙＝泪；海原＝辽阔的海；流れたら＝如果流去。

［夢を濡らした］修饰涙，涙が是流れる的主语；たら提出条件，接下一行的愿望。

濡れる＝被弄湿、湿了；濡らす＝弄湿。

ずっとそばで笑（わら）っていてほしい

希望你一直在我身边微笑。

ずっと＝一直；そばで＝在身旁；笑っていて＝保持微笑；ほしい＝希望。

动词て形＋ほしい：希望别人做；这里含ている，强调持续。省略的动作主体是君。

笑いたい＝我想笑；笑っていてほしい＝希望你持续微笑。

切（き）り札（ふだ）にしてた見（み）えすいた嘘（うそ）は

那句曾被我当作王牌的、一眼就能看穿的谎言，

切り札＝王牌、最后的手段；にしてた＝にしていた；見えすいた＝显而易见、容易看穿的。

［切り札にしてた］和［見えすいた］共同修饰嘘。不是“用尽招数才编出来”。

AをBにする＝把A当作B；这里把嘘提作话题。

満月（まんげつ）の夜（よる）にやぶいた

我在满月之夜，将它撕破了。

満月の夜に＝在满月的夜晚；やぶいた＝破く（やぶく）的过去式。

上行嘘は是被撕毁的对象，动作主体省略；不是谎言自己“破灭”。撕谎言是比喻。

破く＝撕破；破れる＝破了。

はかなく揺（ゆ）れる 髪（かみ）のにおいで

因那轻轻摇曳、带着虚幻感的发丝气息，

はかなく＝短暂、虚幻地；揺れる＝摇曳；髪のにおい＝头发的气息；で＝因、借由。

［はかなく揺れる髪］のにおい；揺れる直接修饰髪，不宜只译成香气在飘荡。

におい是气味；“清香”含好闻的判断，原词本身未限定。

深（ふか）い眠（ねむ）りから覚（さ）めて

从深沉的睡眠中醒来，

深い眠り＝深睡；から＝从；覚める＝醒来。

接上行：因发丝的气息而醒来。覚める是自动词，不是“气味”作主语的他动词句。

目が覚める＝醒来；目を覚ます＝睁眼醒来、唤醒（视语境）。

君（きみ）と出会（であ）った奇跡（きせき）が この胸（むね）にあふれてる

与你相遇的奇迹，洋溢在我心中。

重复第7行；出会った修饰奇跡；あふれてる＝あふれている。

主语是奇跡，地点是この胸に。

把完整句分成：奇跡が／この胸に／あふれている。

きっと今（いま）は自由（じゆう）に空（そら）も飛（と）べるはず

此刻，我一定连天空也能自由飞翔。

重复第8行；飛べる是可能形；はず表示确信。

も把天空加入范围，带连……也的强调。

自由是な形容词：自由な空想／自由に飛ぶ。

ゴミできらめく世界（せかい）が 僕（ぼく）たちを拒（こば）んでも

即使用垃圾闪耀装点的世界拒绝我们，

ゴミ＝垃圾；できらめく＝因……而闪耀；拒む＝拒绝；拒んでも＝即使拒绝。

［ゴミできらめく］修饰世界；世界が是主体，僕たちを是对象。垃圾与闪耀并置，形成反讽式意象。

拒む→拒んで→拒んでも，不是拒みても。

ずっとそばで笑（わら）っていてほしい

仍希望你一直在我身边微笑。

重复第10行；笑っている＋てほしい。

接前行ても：即使世界拒绝我们，也希望你陪伴、微笑。

ても接希望并不矛盾：拒んでも、いてほしい。

君（きみ）と出会（であ）った奇跡（きせき）が この胸（むね）にあふれてる

与你相遇的奇迹，洋溢在我心中。

重复第7、15行；与你相遇是奇跡的修饰语。

出会った表示已经相遇；あふれている表示此刻仍持续的状态。

出会う→出会った；不是出会いた。

きっと今（いま）は自由（じゆう）に空（そら）も飛（と）べるはず

如今，我一定连天空也能自由飞翔。

重复第8、16行；きっと与はず加强信心。

不是已经飞过，也没有要求别人去飞，是对自己能飞的判断。

飛べるはず＝应当能飞；飛んだ＝飞过、飞了。

夢（ゆめ）を濡（ぬ）らした涙（なみだ）が 海原（うなばら）へ流（なが）れたら

如果浸湿梦想的泪水，流向辽阔的大海，

重复第9行；海原へ表示流动方向；たら表示条件。

没有明写“全都”，翻译时无需加上；后项仍是希望对方陪伴。

海原读うなばら；海读うみ。

ずっとそばで笑（わら）っていてほしい

希望你一直在我身边微笑。

重复第10、18行；ていてほしい希望状态持续。

全曲收在对对方的愿望上，微笑的主体是君。

对比：そばにいる＝在身旁；そばで笑う＝在身旁笑。

检测题

1. 「下げられないまま」表示？

  1. 保持无法使其降低的状态
  2. 已经退烧
  3. 必须降温
  4. 一边降低一边走

答案 1　可能形否定＋まま，状态不变。

  • ✓ 可能形否定＋まま，状态不变。
  • 是否定可能。
  • 不是义务。
  • 不是ながら。

まま表示状态保持。

2. 「ナイフが似合わない僕を」中，被安慰的是谁？

  1. 刀
  2. 我
  3. 神明
  4. 歌曲

答案 2　僕を接下行なぐさめた。

  • 刀是似合う的主语。
  • ✓ 僕を接下行なぐさめた。
  • 不是神明。
  • 歌曲是手段。

先连接跨行句，再判断主语和对象。

3. 「飛べるはず」中的はず表示？

  1. 命令
  2. 已经完成
  3. 根据情境相信能做到
  4. 禁止

答案 3　はず表示有依据的预期或确信。

  • 不是命令。
  • 没有表示飞完。
  • ✓ はず表示有依据的预期或确信。
  • 不是禁止。

飞翔的能力用可能形飛べる。

4. 「笑っていてほしい」表示？

  1. 自己想笑
  2. 不要微笑
  3. 已经笑完
  4. 希望对方一直微笑

答案 4　てほしい希望别人做，ている强调持续状态。

  • 自己想笑用笑いたい。
  • 没有否定。
  • 没有完成。
  • ✓ てほしい希望别人做，ている强调持续状态。

区分たい与てほしい。

5. 「見えすいた嘘」最接近？

  1. 一眼就能看穿的谎言
  2. 看不到的谎言
  3. 美丽的约定
  4. 最后才发现的真相

答案 1　見えすいた形容明显、容易识破。

  • ✓ 見えすいた形容明显、容易识破。
  • 不是見えない。
  • 不是约定。
  • 不是真相。

切り札にする＝当作王牌。

6. 「満月の夜にやぶいた」中的やぶいた在本段指？

  1. 月亮自己碎了
  2. 把那句谎言撕破、撕毁了
  3. 被别人骗了
  4. 进入深睡

答案 2　承接前行嘘は，是他动词破く的过去式。

  • 月亮不是对象。
  • ✓ 承接前行嘘は，是他动词破く的过去式。
  • 不是被动。
  • 与睡眠无关。

破く是他动词；破れる是自动词。

7. 「僕たちを拒んでも」中的拒んで来自？

  1. 拒る
  2. 拒ぶ
  3. 拒む
  4. 拒える

答案 3　拒む的て形是拒んで。

  • 没有这个原形。
  • 原形不是拒ぶ。
  • ✓ 拒む的て形是拒んで。
  • 不是这个形式。

む结尾五段动词的て形常为んで。

8. 「そばにいる／そばで笑う」中的に／で分别表示？

  1. 原因／对象
  2. 手段／时间
  3. 对象／原因
  4. 存在位置／动作场所

答案 4　いる的存在位置用に；笑う发生的场所用で。

  • 不是原因或对象。
  • 不是手段或时间。
  • 不是对象或原因。
  • ✓ いる的存在位置用に；笑う发生的场所用で。

存在用に；动作场所用で。
