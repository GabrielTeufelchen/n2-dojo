Automatic

宇多田ヒカル · 2026-11-22

宇多田ヒカル · Automatic · 1998 年单曲官方 MV

从歌里自然涌起的感受，练到日常会脱口说出的「つい」。六句原创练习串起找手机的经过。

学习目标

  • 听出英文歌名切入日语演唱的位置
  • 用つい说出习惯反应
  • 区分动作的线索、触发点和目的

听辨

  • 第一遍听到英文歌名时轻拍一下，留意同一段旋律何时回来。
  • 重听第一次副歌，哼出英文歌名前一句的最后一个音。
  • 任选一处从英文转回日语的地方，暂停，试着模仿转回日语时的节奏。

Vocab

下意识的动作

  • 通知（つうち）　通知、提醒
  • 合図（あいず）　信号
  • つい　不由得

语法

  • つい表示没刻意打算，却做了某个动作。
  • たはずなのに表示记忆中的情况与眼前不符。
  • 名词＋を頼りに，交代行动依靠的线索。
  • たとたん突出紧接着发生的意外反应。
  • 前半是确实做过的事，后半说明结果不如预期。
  • ないように表目的，ておく表提前准备。

逐句学习

原创迁移练习 · 以下六句不是歌词。

通知（つうち）が鳴（な）ると、ついスマホに手（て）が伸（の）びる。

提示音一响，我就忍不住伸手去拿手机。

手が伸びる＝手自然伸过去。

つい表示没刻意打算，却做了某个动作。

用つい说说自己刷手机的习惯。

机（つくえ）の引（ひ）き出（だ）しにしまったはずなのに、スマホがない。

我记得明明把手机收进了抽屉，却找不到了。

しまう＝收起来。

たはずなのに表示记忆中的情况与眼前不符。

记忆中手机在哪里？

音（おと）を頼（たよ）りに、かばんの中（なか）を探（さが）した。

我循着声音在包里找。

音を頼りに＝以声音为线索。

名词＋を頼りに，交代行动依靠的线索。

把线索换成地图。

画面（がめん）を見（み）たとたん、昨日（きのう）の約束（やくそく）を思（おも）い出（だ）した。

屏幕一映入眼帘，我猛地想起了昨天的约定。

思い出す＝想起来。

たとたん突出紧接着发生的意外反应。

先看到屏幕，还是先想起约定？

急（いそ）いで電話（でんわ）したものの、もう誰（だれ）もいなかった。

我赶紧打了电话，可是已经没人了。

電話した＋ものの＝虽然打了电话。

前半是确实做过的事，后半说明结果不如预期。

改用「けれど」连接。

次（つぎ）は忘（わす）れないように、今（いま）からアラームをセットしておく。

为了下次记得，我现在就先设好闹钟。

セットしておく＝先设置好。

ないように表目的，ておく表提前准备。

想避免的是忘记，还是设闹钟？

检测题

1. 通知が鳴ると、ついスマホに手が伸びる。「つい」是什么感觉？

  1. 特地去拿
  2. 不知不觉就伸手
  3. 终于拿到
  4. 绝不伸手

答案 2　つい说明伸手是下意识的。

  • 特地是有意识地做。
  • ✓ 提示音触发了习惯动作。
  • 句子没说等了很久。
  • 手已经伸了过去。

つい＋动作。

2. 「しまったはずなのに、スマホがない。」说话人怎样理解现状？

  1. 肯定被偷了
  2. 计划稍后收好
  3. 眼前情况与记忆不符
  4. 刚把手机扔掉

答案 3　はず表示心中的预期，なのに引出反常情况。

  • 未提被盗。
  • しまった是过去式。
  • ✓ 记得收好了，眼下却找不到。
  • しまう在这里是收起。

先分清预期和观察。

3. 音（　）頼りに、かばんの中を探した。

  1. を
  2. で
  3. と
  4. が

答案 1　循声寻找时，声音是线索。

  • ✓ 音を頼りに＝循着声音。
  • で不能直接接这里的頼りに。
  • と不能标出依靠的线索。
  • が把声音标成了主语。

线索＋を頼りに。

4. 「画面を見たとたん、約束を思い出した。」哪项最接近？

  1. 看之前就记得
  2. 一直盯着才想起
  3. 为了回忆才看
  4. 一看就想起来了

答案 4　とたん标出后一个动作发生的瞬间。

  • 先看屏幕。
  • 中间没有长时间等待。
  • 说的是意外反应。
  • ✓ 两件事紧挨着发生。

动词た形＋とたん。

5. 急いで電話した（　）、誰も出なかった。要表达“虽然打了”。

  1. おかげで
  2. ものの
  3. 以上に
  4. ために

答案 2　电话已经打过；后半句交代落空的期待。

  • 表示有利原因。
  • ✓ 打了，但没人接。
  • 表示超过某个程度。
  • 表示原因或目的。

普通形＋ものの。

6. 「忘れないように、アラームをセットしておく。」提前做了什么？

  1. 忘了约定
  2. 等闹钟响
  3. 设好闹钟
  4. 取消约定

答案 3　ておく接在セットする后面，说明先做这件事。

  • 忘记是想避免的事。
  • 句中没有等待。
  • ✓ 设置闹钟是准备动作。
  • 没有取消。

注意目的和手段的顺序。
