前前前世（ぜんぜんぜんせ）

RADWIMPS · 2026-10-28

《你的名字。》相关歌曲。本课听官方 movie ver. MV，用原创句练习相遇、寻找与时间表达。

学习目标

  • 听辨快节奏下的长音、促音与换气
  • 区分ようにする和ようになる
  • 用て以来、までに、としても与ような気がする表达经历和判断

听辨

  • 第一遍完整听，留意主歌与副歌的节奏变化，先不追求逐字听懂。
  • 第二遍选5～10秒回听，标出自己听清的音节，注意快唱不等于省掉所有长音或促音。
  • 第三遍对比人声和鼓点，跟读最清楚的一小段；下面6句用于语法迁移，不是歌曲歌词。

Vocab

相遇与记忆。

  • 偶然（ぐうぜん）　偶然。
  • 再会（さいかい）　重逢。
  • 記憶（きおく）　记忆。
  • 探（さが）す　寻找。

语法

  • 〜ようにする：有意识地去做
  • 〜ようになる：状态或能力发生变化
  • 〜て以来：自从……以后一直
  • 〜までに：在期限前完成
  • 〜としても：即使假定……
  • 〜ような気がする：觉得好像……

逐句学习

原创迁移练习 · 以下6句不是歌词。

毎日（まいにち）短（みじか）い音声（おんせい）を聞（き）くようにしている。

我坚持每天听一小段音频。

聞くようにしている＝有意识地坚持听。

ようにする表示主动努力；不是能力自然发生变化。

与今天进阶课配合：自分で決めた習慣＝自己决定的习惯。

前（まえ）より速（はや）い日本語（にほんご）も聞（き）き取（と）れるようになった。

我变得连比以前更快的日语也能听懂了。

聞き取れる＝能够听清、听懂；ようになった＝变得能够。

可能形＋ようになる表示能力变化；与ようにする区分。

聞くようにする＝尽量听；聞き取れるようになる＝变得听得懂。

彼（かれ）に会（あ）って以来（いらい）、毎日（まいにち）連絡（れんらく）を取（と）っている。

自从见到他以后，我每天都与他联系。

会って以来＝自从见面以来；連絡を取る＝联系。

て以来以过去某个事件为起点，后项说明此后持续的情况。

以来通常不能只接一次性的未来打算。

待（ま）ち合（あ）わせの時間（じかん）までに、駅（えき）に着（つ）きたい。

我想在约定的时间之前到达车站。

待ち合わせ＝约好碰面；までに＝在期限前；着く＝到达。

までに强调完成的期限；まで强调状态或动作持续到某时。

9時まで待つ＝等到9点；9時までに着く＝9点前到达。

もしまた離（はな）れるとしても、連絡（れんらく）は続（つづ）けたい。

即使假如我们再次分开，我也想继续联系。

離れる＝分开；としても＝即使假定；続けたい＝想继续。

普通形＋としても提出让步假设，不表示前项已经确定发生。

名词接だとしても，如遠距離だとしても。

この場所（ばしょ）には、前（まえ）にも来（き）たような気（き）がする。

我觉得自己好像以前也来过这里。

前にも＝以前也；来たような＝仿佛来过；気がする＝觉得。

ような気がする表达不确定的感觉，不等于确认发生过。

来たことがある＝有来过的经历，语气更确定。

检测题

1. 勉強のため、毎日日本語を聞く（　）している。

  1. ように
  2. ような
  3. ためを
  4. はずが

答案 1　ようにする表示有意识地去做。

  • ✓ ようにする表示有意识地去做。
  • ような修饰名词，不能接这里的する。
  • 接续不成立。
  • 接续不成立。

ようにする＝主动坚持。

2. 「聞き取れるようになった」が表すのは？

  1. 要求别人听
  2. 决定去听
  3. 能力发生了变化
  4. 根本没有听

答案 3　以前不会或较弱，现在变得能够。

  • 没有请求。
  • 决定做可用ようにする。
  • ✓ 以前不会或较弱，现在变得能够。
  • 没有否定。

可能形＋ようになる：变得能够。

3. 彼に会って（　）、毎日連絡を取っている。

  1. ばかりを
  2. 以来
  3. ままで
  4. ほどに

答案 2　以会面为起点，之后每天保持联系。

  • 不能这样接。
  • ✓ 以会面为起点，之后每天保持联系。
  • 表示状态保持，不合此句。
  • 表示程度，不合此句。

て以来：从某事件以后一直。

4. 「9時までに着く」と「9時まで待つ」の違いは？

  1. 都表示9点后开始
  2. 前者持续等待，后者到达期限
  3. 两个都表示到达
  4. 前者到达期限，后者等待终点

答案 4　までに强调完成期限；まで强调持续终点。

  • 没有9点后开始。
  • 两者颠倒。
  • 待つ不是到达。
  • ✓ までに强调完成期限；まで强调持续终点。

区分まで和までに。

5. 「離れるとしても」の意味は？

  1. 即使假如分开
  2. 已经决定不分开
  3. 因为分开了
  4. 必须分开

答案 1　としても提出让步假设。

  • ✓ としても提出让步假设。
  • 没有决定或否定。
  • 没有确认已经分开。
  • 没有义务。

としても不等于前项已经发生。

6. 「来たような気がする」は？

  1. 确定从未来过
  2. 觉得好像来过
  3. 命令别人过来
  4. 刚刚到了

答案 2　表达主观、不确定的感觉。

  • 没有确定否定。
  • ✓ 表达主观、不确定的感觉。
  • 没有命令。
  • 不是たばかり。

ような気がする：感觉好像……。
