粉雪（こなゆき）

レミオロメン · 2026-11-11

2005年单曲《粉雪》，日剧《1リットルの涙》插曲。使用官方原曲MV；围绕冬日、距离与回忆练习。下方6句为原创迁移例句，不是歌词。

学习目标

  • 听辨抒情演唱中延长的元音
  • 用ほど说明程度，用ため说明原因
  • 区分每次发生与逐渐变化

听辨

  • 第一遍完整听，比较主歌与副歌的音量、音域变化。
  • 第二遍选5～10秒回听，留意拖长元音时辅音起点在哪里；不要把长音误当成多一个词。
  • 第三遍模仿同一短段，先说再唱；最后用原创句讲一次冬天的经历。

Vocab

冬日与回忆

  • 粉雪（こなゆき）　细粉状的雪
  • 距離（きょり）　距离
  • 思（おも）い出（で）　回忆

语法

  • につれて：随变化
  • ほど：程度
  • ため：原因
  • からといって：不能据此断定
  • てたまらない：强烈感受
  • たびに：每次

逐句学习

原创迁移练习 · 以下6句不是歌词。

雪（ゆき）が降（ふ）るにつれて、街（まち）の音（おと）が静（しず）かになった。

随着雪落下，街上的声音安静了下来。

街の音＝街上的声音。

につれて：伴随前项变化，后项也变化。

降る＋につれて。

窓（まど）の外（そと）は真（ま）っ白（しろ）で、道（みち）が見（み）えないほどだ。

窗外一片雪白，连路都快看不清了。

真っ白＝雪白；道＝道路。

ほど：用结果说明程度。

見えない＝看不见；見ない＝不看。

電車（でんしゃ）が止（と）まったため、家（いえ）まで歩（ある）いて帰（かえ）った。

因为电车停运，我走回了家。

止まる＝停止；歩いて帰る＝走回去。

ため：表示原因，后项是客观结果。

止まったため＝因为停了。

寒（さむ）いからといって、一日中（いちにちじゅう）部屋（へや）にいるわけではない。

虽说天气冷，我也并非一整天都待在房间里。

一日中＝一整天。

からといって：不能仅凭前项推出后项。

わけではない：部分否定。

久（ひさ）しぶりに友達（ともだち）に会（あ）えて、うれしくてたまらない。

久违地见到朋友，我高兴极了。

会えて＝能见面，て形连接原因。

てたまらない：感受强烈得难以抑制。

うれしい→うれしくて。

手紙（てがみ）を読（よ）み返（かえ）すたびに、あの冬（ふゆ）を思（おも）い出（だ）す。

每次重读信件，我都会想起那个冬天。

読み返す＝重读。

たびに：每次前项发生，都会出现后项。

名词接のたびに；动词用辞书形。

检测题

1. 「雪が降るにつれて、街が静かになる」は？

  1. 雪落下后街上逐渐安静
  2. 虽然下雪却很吵
  3. 为了下雪而安静
  4. 禁止下雪

答案 1　前后变化相伴。

  • ✓ 前后变化相伴。
  • 不是逆接。
  • 不是目的。
  • 没有禁止。

につれて：相伴变化。

2. 「道が見えないほど白い」强调什么？

  1. 看路的目的
  2. 白的程度
  3. 道路的位置
  4. 是否想看

答案 2　用看不清路说明白的程度。

  • 不是目的。
  • ✓ 用看不清路说明白的程度。
  • 不是位置。
  • 不是愿望。

ほど：程度。

3. 電車が止まった（　）、歩いて帰った。

  1. ためにする
  2. ようになる
  3. ため
  4. にとって

答案 3　た形＋ため，说明原因。

  • 不能这样连接原因。
  • 不表示这件事的原因。
  • ✓ た形＋ため，说明原因。
  • 立场表达，前接名词。

ため：原因；辞书形＋ために也可表目的。

4. 「寒いからといって、一日中部屋にいるわけではない」は？

  1. 冷就一定不出门
  2. 一整天都在外面
  3. 不觉得冷
  4. 冷也不代表整天待屋里

答案 4　否定从寒冷到整天在屋内的推论。

  • 后项否定这个推论。
  • 没有说整天在外面。
  • 没有否定寒冷。
  • ✓ 否定从寒冷到整天在屋内的推论。

からといって～わけではない。

5. 「うれしくてたまらない」は？

  1. 高兴极了
  2. 不能高兴
  3. 不怎么高兴
  4. 已经忘了高兴

答案 1　强烈感受。

  • ✓ 强烈感受。
  • 不是能力否定。
  • 不是程度低。
  • 不是遗忘。

い形去い＋くてたまらない。

6. 読み返す（　）、冬を思い出す。

  1. ためだった
  2. たびに
  3. のたびに
  4. に比べて

答案 2　辞书形＋たびに，表示每次。

  • 不能这样连接。
  • ✓ 辞书形＋たびに，表示每次。
  • 名词才接のたびに。
  • 动词辞书形不能直接接に比べて。

动词辞书形＋たびに。
