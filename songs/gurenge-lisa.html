Vocab

努力与成长

  • 努力（どりょく）　努力
  • 目標（もくひょう）　目标
  • 実力（じつりょく）　实力

语法

  • に応じて：根据情况调整
  • からこそ：正因为
  • たとえ〜ても：即使
  • ずにはいられない：忍不住
  • ようとする：试图
  • ことはない：不必

逐句学习

原创迁移练习 · 以下6句不是歌词。

実力（じつりょく）に応（おう）じて、練習（れんしゅう）の内容（ないよう）を変（か）えよう。

根据实力调整练习内容吧。

実力＝实力；内容を変える＝改变内容。

に応じて：配合程度、情况作调整。

人数に応じて＝根据人数。

大切（たいせつ）な目標（もくひょう）だからこそ、簡単（かんたん）には諦（あきら）めたくない。

正因为是重要的目标，才不想轻易放弃。

だからこそ＝正因为；諦める＝放弃。

からこそ：强调原因；名词、な形容词接だからこそ。

大切だ＋からこそ。

たとえ時間（じかん）がかかっても、最後（さいご）まで続（つづ）けたい。

即使花时间，也想坚持到底。

時間がかかる＝花时间；最後まで＝直到最后。

たとえ＋ても：即使假设成真，后项也不变。

たとえ失敗しても＝即使失败。

友達（ともだち）の努力（どりょく）を見（み）て、応援（おうえん）せずにはいられなかった。

看到朋友的努力，忍不住为他加油。

応援する＝支持、加油；せず＝不做。

ずにはいられない：无法抑制；する→せず。

応援しないではいられない意思相同。

彼（かれ）は何度（なんど）も立（た）ち上（あ）がろうとした。

他多次试图站起来。

何度も＝多次；立ち上がる＝站起来。

意向形＋とする：试图做；不保证成功。

立ち上がる→立ち上がろう。

一度（いちど）失敗（しっぱい）しただけで、自分（じぶん）を責（せ）めることはない。

不必因为一次失败就责怪自己。

一度＝一次；責める＝责怪。

辞书形＋ことはない：没必要做。

区别たことがない：没有做过。

检测题

1. 実力（　）、練習内容を変える。

  1. に応じて
  2. のまま
  3. をこめて
  4. に反して

答案 1　根据实力调整。

  • ✓ 根据实力调整。
  • 原样不变不合。
  • 倾注感情不合。
  • 与实力相反不合。

に応じて：根据情况调整。

2. 「大切だからこそ」は？

  1. 虽然重要
  2. 正因为重要
  3. 重要之前
  4. 完全不重要

答案 2　强调原因。

  • 不是让步。
  • ✓ 强调原因。
  • 不是时间。
  • 没有否定。

からこそ：正因为。

3. たとえ失敗し（　）、続けたい。

  1. たまで
  2. ただけ
  3. ても
  4. ながらを

答案 3　即使失败也想继续。

  • 接续不合。
  • 仅仅失败不合。
  • ✓ 即使失败也想继续。
  • 接续不合。

たとえ〜ても：即使。

4. 応援する＋ずにはいられない＝？

  1. 応援するずにはいられない
  2. 応援しずにはいられない
  3. 応援さずにはいられない
  4. 応援せずにはいられない

答案 4　する→せず。

  • する需变形。
  • する不用しず。
  • する不用さず。
  • ✓ する→せず。

する的ず形是せず。

5. 「立ち上がろうとした」は？

  1. 试图站起来
  2. 已经站了很久
  3. 不能站起来
  4. 命令别人站起来

答案 1　意向形＋とする表示尝试。

  • ✓ 意向形＋とする表示尝试。
  • 未表示持续。
  • 不是能力否定。
  • 没有命令。

ようとする不保证动作成功。

6. 「自分を責めることはない」は？

  1. 从未责怪自己
  2. 不必责怪自己
  3. 禁止自己说话
  4. 一定责怪自己

答案 2　表示没有必要。

  • 经历否定用たことがない。
  • ✓ 表示没有必要。
  • 没有说话。
  • 与原意相反。

辞书形＋ことはない：不必。
