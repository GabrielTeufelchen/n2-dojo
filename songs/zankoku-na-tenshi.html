《新世纪福音战士》主题歌。播放器为官方 MUSIC VIDEO（HDver.），2018年公开。下方是原创练习，不是逐句歌词。

学习目标

  • 听辨快节奏中的促音、长音和句尾
  • 结合今日进阶课区分に違いない与かもしれない
  • 练习成长、选择与不安的表达

听辨

  • 完整听一遍，留意开头与副歌的节奏变化。
  • 选听清的5～10秒重复两遍，辨认长音、促音与助词。
  • 先按说话速度模仿一个听清的短段，再随音乐跟唱；不要把延长音当成新增音节。

Vocab

成长与选择。

  • 勇気（ゆうき）　勇气
  • 選択（せんたく）　选择
  • 不安（ふあん）　不安
  • 成長（せいちょう）　成长

语法

  • に違いない：有把握的推断
  • かもしれない：可能
  • わけではない：并非
  • ながらも：虽然却
  • ために：为了
  • ようになる：变得能够

逐句学习

原创迁移练习 · 以下6句不是歌词。

毎日（まいにち）練習（れんしゅう）しているから、彼（かれ）は上手（じょうず）になるに違（ちが）いない。

他每天练习，一定会进步。

毎日＝每天；上手になる＝变熟练。

に違いない：说话人很有把握的推断。

换成かもしれない：可能会进步，语气更弱。

新（あたら）しい挑戦（ちょうせん）は、自分（じぶん）を変（か）えるきっかけになるかもしれない。

新的挑战也许会成为改变自己的契机。

きっかけ＝契机；変える＝改变。

かもしれない：保留不确定性。

对比に違いない：一定会成为契机。

怖（こわ）いからといって、何（なに）もできないわけではない。

感到害怕，并不代表什么都做不了。

怖い＝害怕；何もできない＝什么都做不了。

からといって＋否定：不能仅凭前项下结论。

わけではない＝并非；不是全面否定害怕。

不安（ふあん）を感（かん）じながらも、彼女（かのじょ）は一歩（いっぽ）前（まえ）へ進（すす）んだ。

她虽然不安，仍向前迈了一步。

不安を感じる＝感到不安；一歩＝一步。

ながらも：承认前项，却出现相反的行动。

动词ます形去ます＋ながらも。

自分（じぶん）で選（えら）ぶために、まず情報（じょうほう）を集（あつ）めよう。

为了自己作选择，先搜集信息吧。

自分で＝自己；情報を集める＝搜集信息。

意志动词原形＋ために：主动行动的目的。

集めよう＝一起搜集吧／我要搜集。

失敗（しっぱい）を重（かさ）ねるうちに、落（お）ち着（つ）いて話（はな）せるようになった。

经历多次失败后，逐渐能冷静地说话了。

失敗を重ねる＝经历多次失败；話せる＝能说。

うちに：过程中逐渐变化；可能形＋ようになる：能力变化。

話すようになった＝开始经常说；話せるようになった＝变得能说。

检测题

1. 「上手になるに違いない」の気持ちは？

  1. 一定会进步
  2. 可能进步，也可能不进步
  3. 禁止进步
  4. 已经进步了

答案 1　有把握的推断。

  • ✓ 有把握的推断。
  • 这是较弱的可能性。
  • 没有禁止。
  • なる表示变化，不是过去完成。

に違いない：确信的推断，不是客观保证。

2. 「きっかけになるかもしれない」は？

  1. 必定成为契机
  2. 也许成为契机
  3. 不可能成为契机
  4. 必须成为契机

答案 2　表示一种可能。

  • 语气过强。
  • ✓ 表示一种可能。
  • 与可能相反。
  • 没有义务。

かもしれない：可能。

3. 「何もできないわけではない」は？

  1. 什么都做不了
  2. 所有事情都能做
  3. 并非什么都做不了
  4. 什么都不想做

答案 3　否定“完全做不了”。

  • わけではない否定这一判断。
  • 没有保证全部能做。
  • ✓ 否定“完全做不了”。
  • 能力与意愿不同。

わけではない：并非。

4. 不安を感じ（　）、前へ進んだ。

  1. ためを
  2. だけが
  3. までを
  4. ながらも

答案 4　虽不安，仍前进。

  • 接续不成立。
  • 接续不成立。
  • 接续不成立。
  • ✓ 虽不安，仍前进。

ます形词干＋ながらも：虽然却。

5. 「自分で選ぶために、情報を集める」の目的は？

  1. 自己作选择
  2. 收集他人的物品
  3. 放弃选择
  4. 忘掉信息

答案 1　为自己作选择而搜集信息。

  • ✓ 为自己作选择而搜集信息。
  • 情報是信息。
  • 没有放弃。
  • 没有忘记。

ために前面是目的。

6. 「話せるようになった」は？

  1. 被要求说话
  2. 变得能说话了
  3. 再也不说话
  4. 别人替自己说

答案 2　可能形＋ようになる表示能力变化。

  • 没有要求。
  • ✓ 可能形＋ようになる表示能力变化。
  • 没有否定。
  • 没有代替。

話せる＝話す的可能形。
