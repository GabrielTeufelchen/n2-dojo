YOASOBI · 夜に駆ける · 官方发行音频视频（2019，非MV）

Vocab

约定与变化

  • 予定（よてい）　计划
  • 連絡（れんらく）　联系
  • 約束（やくそく）　约定

语法

  • ことになっている：规定、安排
  • ように言う：转述要求
  • ても：即使
  • まま：保持状态
  • ところだった：差点
  • につれて：随着

逐句学习

原创迁移练习 · 以下6句不是歌词。

明日（あした）は駅（えき）で待（ま）ち合（あ）わせることになっている。

安排好明天在车站碰面。

待ち合わせる＝碰面。

ことになっている：已定安排，也可表示规定。

对比ことにした：自己决定。

先生（せんせい）に、遅（おく）れないように言（い）われた。

老师叮嘱我别迟到。

遅れない＝不迟到；言われた＝被告知。

ように言う：转述指示、要求。

直接说法：遅れないでください。

雨（あめ）が降（ふ）っても、約束（やくそく）の場所（ばしょ）へ行（い）く。

即使下雨，也去约定的地方。

降っても＝即使下雨；場所＝地点。

ても：假设前项发生，后项仍成立。

晴れても＝即使放晴。

窓（まど）を開（あ）けたまま、眠（ねむ）ってしまった。

窗户开着就睡着了。

開けたまま＝保持开着；眠る＝睡。

たまま：做完某动作后，状态保持不变。

閉めたまま＝保持关着。

友達（ともだち）から連絡（れんらく）がなければ、約束（やくそく）を忘（わす）れるところだった。

要不是朋友联系我，我差点忘了约定。

連絡がなければ＝若没有联系。

辞书形＋ところだった：差点发生，但未发生。

忘れたところだ＝刚忘记，意思不同。

日本語（にほんご）に慣（な）れるにつれて、歌（うた）も聞（き）き取（と）りやすくなった。

随着日语越来越熟悉，歌也更容易听懂了。

慣れる＝熟悉；聞き取りやすい＝容易听清。

につれて：前后两项随进展而变化。

上達するにつれて＝随着进步。

检测题

1. 「会うことになっている」は？

  1. 已有见面安排
  2. 刚刚见过
  3. 从未见过
  4. 不准见面

答案 1　表示已定安排。

  • ✓ 表示已定安排。
  • 没有刚刚。
  • 不是经历否定。
  • 没有禁止。

ことになっている：已定安排。

2. 「遅れないように言われた」は？

  1. 被夸奖了
  2. 被叮嘱不要迟到
  3. 决定迟到
  4. 听不清声音

答案 2　转述要求。

  • 没有夸奖。
  • ✓ 转述要求。
  • 不是主动决定。
  • 不是听力能力。

ように言う：转述要求。

3. 雨が降っ（　）、行きます。

  1. たらこそ
  2. たりに
  3. ても
  4. ながらを

答案 3　即使下雨也去。

  • 接续不合。
  • 接续不合。
  • ✓ 即使下雨也去。
  • 接续不合。

ても：即使。

4. 「窓を開けたまま眠った」は？

  1. 关窗后睡
  2. 边开窗边睡
  3. 从未开窗
  4. 窗开着睡了

答案 4　开窗后的状态持续。

  • 窗未关。
  • 不是两动作同时进行。
  • 已开窗。
  • ✓ 开窗后的状态持续。

たまま：保持状态。

5. 「忘れるところだった」は？

  1. 差点忘记
  2. 刚忘记了
  3. 正在忘记
  4. 一定会忘记

答案 1　表示险些发生。

  • ✓ 表示险些发生。
  • 刚做完是たところ。
  • 不是正在。
  • 不是确信推测。

ところだった：差点。

6. 「慣れるにつれて」の意味は？

  1. 熟悉之前
  2. 随着逐渐熟悉
  3. 虽然熟悉
  4. 为了熟悉

答案 2　随着前项进展，后项变化。

  • 不是之前。
  • ✓ 随着前项进展，后项变化。
  • 不是让步。
  • 不是目的。

につれて：随着变化。
