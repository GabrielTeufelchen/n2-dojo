学习目标

  • 区分歌曲中的短音节和拖长元音

  • 用さえ～ば、どうであれ表达条件与让步

听辨

  • 第一遍听完整段PV，留意音乐与对白的切换，只模仿歌声部分。
  • 第二遍选一句听清的短段，回听辅音起点与元音延长；先打拍子再跟读。
  • 第三遍重复同一短段，比较自己说话与跟唱时的节奏；用原创句描述一次尝试。

Vocab

冒险与伙伴

  • 冒険（ぼうけん）　冒险
  • 仲間（なかま）　伙伴
  • 勇気（ゆうき）　勇气

语法

  • のに：逆接
  • たところ：做后发现
  • たほうがいい：建议
  • ように／ておく：避免与准备
  • さえ～ば：只要
  • どうであれ：无论怎样

逐句学习

原创迁移练习 · 以下6句不是歌词。

初（はじ）めての旅（たび）だったのに、不思議（ふしぎ）と不安（ふあん）はなかった。

明明是第一次旅行，我却意外地不觉得不安。

不思議と＝不可思议地、出乎意料地。

のに：结果与预期相反。

名词＋だったのに。

地図（ちず）を見（み）たところ、目的地（もくてきち）は意外（いがい）に近（ちか）かった。

看过地图才发现，目的地意外地近。

目的地＝目的地；意外に＝意外地。

たところ：做了前项后，发现后项。

見たところ：这里是看后发现，不是見たところだ的刚看完。

一人（ひとり）で悩（なや）むより、仲間（なかま）に相談（そうだん）したほうがいい。

与其独自烦恼，不如和伙伴商量。

悩む＝烦恼；相談する＝商量。

より～ほうがいい：比较后提出建议。

相談する→相談したほうがいい。

道（みち）に迷（まよ）わないように、駅（えき）の名前（なまえ）をメモしておいた。

为了不迷路，我提前记下了车站名。

道に迷う＝迷路。

ないように：避免某种情况；ておく：提前准备。

迷わないように＝以免迷路。

勇気（ゆうき）さえあれば、新（あたら）しい環境（かんきょう）でもやっていける。

只要有勇气，即使在新环境里也能坚持下去。

やっていける＝能继续应付、生活下去。

さえ～ば：只要满足这个条件。

名词＋さえあれば。

結果（けっか）がどうであれ、挑戦（ちょうせん）したことには意味（いみ）がある。

不管结果如何，尝试过就有意义。

意味がある＝有意义。

どうであれ：无论怎样。

挑戦したこと：把经历名词化。

检测题

1. 「初めての旅だったのに、不安はなかった」は？

  1. 第一次旅行却不担心
  2. 因为旅行所以担心
  3. 从来没旅行过
  4. 不能去旅行

答案 1　与通常预期相反。

  • ✓ 与通常预期相反。
  • 不是原因关系。
  • 说的是首次旅行。
  • 没有能力否定。

のに：逆接。

2. 「地図を見たところ、目的地は近かった」は？

  1. 正准备看地图
  2. 看地图后发现目的地近
  3. 为了让目的地变近
  4. 没看过地图

答案 2　前项动作带来发现。

  • 不是准备。
  • ✓ 前项动作带来发现。
  • 不是目的。
  • 見た是过去肯定。

たところ：做后发现。

3. 友達に相談（　）ほうがいい。

  1. するの
  2. しての
  3. した
  4. したいの

答案 3　动词た形＋ほうがいい提出建议。

  • 这里不接するの。
  • 接续不成立。
  • ✓ 动词た形＋ほうがいい提出建议。
  • 意思与接续不合。

た形＋ほうがいい。

4. 「メモしておいた」は？

  1. 忘了做笔记
  2. 被要求做笔记
  3. 边走边写
  4. 提前记下来了

答案 4　ておく表示预先准备。

  • 不是忘记。
  • 不是被动。
  • 没有同时动作。
  • ✓ ておく表示预先准备。

ておく：提前做。

5. 勇気（　）あれば、やっていける。

  1. さえ
  2. しか
  3. だけに
  4. こそは

答案 1　さえ～ば表示最低必要条件。

  • ✓ さえ～ば表示最低必要条件。
  • しか通常与否定配合。
  • だけに表示相应原因。
  • 这里不是合适的条件结构。

名词＋さえあれば。

6. 「結果がどうであれ」は？

  1. 结果很好才
  2. 无论结果如何
  3. 因为结果差
  4. 结果还不知道所以

答案 2　结果怎样都不影响后项。

  • 不限定好结果。
  • ✓ 结果怎样都不影响后项。
  • 不是原因。
  • 重点不是未知造成原因。

どうであれ：无论怎样。
