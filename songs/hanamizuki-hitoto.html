Vocab

牵挂与祝愿

  • 幸（しあわ）せ　幸福
  • 見守（みまも）る　守望、关注
  • 願（ねが）う　祈愿

语法

  • ように：祝愿
  • にしても：即便
  • わけにはいかない：情理上不能
  • につれて：随着
  • 続ける：持续做
  • ことを願う：希望某事实现

逐句学习

原创迁移练习 · 以下6句不是歌词。

大切（たいせつ）な人（ひと）が、ずっと幸（しあわ）せでいられますように。

愿重要的人能一直幸福。

幸せでいられる＝能保持幸福。

ますように：祈愿；不是对对方下命令。

合格できますように＝愿能合格。

遠（とお）くに住（す）むにしても、連絡（れんらく）は取（と）り合（あ）いたい。

即使住得远，也想相互保持联络。

連絡を取り合う＝互相联系。

にしても：即便承认某条件，后项仍成立。

引っ越すにしても＝即使搬家。

心配（しんぱい）でも、相手（あいて）の気持（きも）ちを無視（むし）するわけにはいかない。

即使担心，也不能不顾对方的感受。

無視する＝忽视；相手＝对方。

わけにはいかない：受情理或责任约束而不能。

無視できない侧重不能忽视；本句强调情理。

時（とき）がたつにつれて、感謝（かんしゃ）の気持（きも）ちが深（ふか）まった。

随着时间流逝，感谢之情愈发深厚。

時がたつ＝时间流逝；深まる＝加深。

につれて：前项进展伴随后项变化。

慣れるにつれて＝随着逐渐熟悉。

会（あ）えない間（あいだ）も、友達（ともだち）の成功（せいこう）を祈（いの）り続（つづ）けた。

不能见面的日子里，我也一直祝愿朋友成功。

成功を祈る＝祝愿成功。

ます形去ます＋続ける：持续做某动作。

祈ります→祈り続ける。

また笑顔（えがお）で会（あ）えることを、心（こころ）から願（ねが）っています。

衷心希望我们能再次笑着相见。

笑顔で＝带着笑容；心から＝衷心地。

句子＋こと将愿望内容名词化，再接を願う。

会える＝能见面，是会う的可能形。

检测题

1. 「幸せでいられますように」は？

  1. 祝愿对方幸福
  2. 命令对方工作
  3. 说明过去失败
  4. 拒绝对方

答案 1　句末ように表示祝愿。

  • ✓ 句末ように表示祝愿。
  • 不是命令。
  • 不是失败。
  • 没有拒绝。

ますように：愿……。

2. 「遠くに住むにしても」は？

  1. 因为住得近
  2. 即便住得远
  3. 从未住过
  4. 必须住很远

答案 2　承认假设条件。

  • 不是原因或近。
  • ✓ 承认假设条件。
  • 不是经历。
  • 没有义务。

にしても：即便。

3. 「無視するわけにはいかない」は？

  1. 随便忽视
  2. 想要忽视
  3. 情理上不能忽视
  4. 从未见过

答案 3　因情理、责任而不能做。

  • 有约束。
  • 不是愿望。
  • ✓ 因情理、责任而不能做。
  • 不是经历。

わけにはいかない：有约束而不能。

4. 時がたつ（　）、気持ちが深まった。

  1. までを
  2. ためが
  3. ところをも
  4. につれて

答案 4　随时间推移而变化。

  • 接续不合。
  • 接续不合。
  • 接续不合。
  • ✓ 随时间推移而变化。

につれて：随着变化。

5. 祈る＋続ける＝？

  1. 祈り続ける
  2. 祈る続ける
  3. 祈って続けるだけ
  4. 祈れ続ける

答案 1　ます形词干＋続ける。

  • ✓ ます形词干＋続ける。
  • 不用辞书形直接接。
  • 不是目标词形。
  • 不用命令形。

祈ります→祈り続ける。

6. 「会えることを願う」は？

  1. 拒绝见面
  2. 希望能见面
  3. 已经见过
  4. 禁止见面

答案 2　こと把愿望内容名词化。

  • 不是拒绝。
  • ✓ こと把愿望内容名词化。
  • 不是经历。
  • 不是禁止。

内容＋ことを願う。
