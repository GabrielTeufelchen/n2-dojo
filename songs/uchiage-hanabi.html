打上花火（うちあげはなび）

DAOKO × 米津玄師 · 2026-10-20

围绕夏日、烟花和回忆练听辨与语法。当前为原创练习；提供歌词后可补逐句歌词讲解。

学习目标

  • 听辨双人演唱中的换气与接句
  • 掌握うちに、たびに、ように和ばよかった
  • 用原创例句练习描述回忆

听辨

  • 先完整听，分辨两位歌手的声线与交接。
  • 再听副歌，留意长音、促音与重复的旋律。
  • 选一小段回听，用自己的话描述情绪，再做下面的原创练习。

Vocab

烟花与夏日。

  • 花火（はなび）　烟花。
  • 砂浜（すなはま）　沙滩。
  • 打（う）ち上（あ）げる　向上发射、升空。
  • 思（おも）い出（で）　回忆。

语法

  • 〜うちに：趁……、在……期间
  • 〜たびに：每当……
  • 〜ように：为了使……
  • 〜ばよかった：早知道……就好了

逐句学习

原创练习 · 不是歌词。

暗（くら）くなる前（まえ）に、海（うみ）へ行（い）こう。

天黑之前，去海边吧。

暗くなる＝变暗；前に＝之前；行こう＝去吧。

动词原形＋前に；行こう是行く的意志形。

行く→行こう。

夏（なつ）が終（お）わらないうちに、もう一度（いちど）会（あ）いたい。

趁夏天还没结束，想再见你一次。

終わらない＝尚未结束；うちに＝趁……；もう一度＝再一次。

ないうちに表示趁某种变化尚未发生。

暗くならないうちに帰ろう＝趁天还没黑回去吧。

この曲（きょく）を聞（き）くたびに、あの夏（なつ）を思（おも）い出（だ）す。

每次听这首歌，都会想起那个夏天。

聞くたびに＝每次听；あの夏＝那个夏天；思い出す＝想起。

动词原形＋たびに，表示每次前项发生都出现后项。

たびに不等于たまに（偶尔）。

花火（はなび）が消（き）えても、景色（けしき）は心（こころ）に残（のこ）っている。

即使烟花消散，景色仍留在心里。

消える＝消失；ても＝即使；残っている＝仍保留。

ても表示让步；残っている表示持续的结果状态。

消える是自动词；消す是他动词。

忘（わす）れないように、今日（きょう）のことを書（か）いておく。

为了不忘记，把今天的事先记下来。

忘れないように＝为了不忘；書いておく＝先写下。

ないように表示避免某结果的目的；ておく表示提前准备。

書いておく→口语書いとく。

あのとき、もっと写真（しゃしん）を撮（と）ればよかった。

早知道那时候多拍些照片就好了。

あのとき＝那时；もっと＝更多；撮ればよかった＝早知道拍就好了。

ばよかった表达对未做或未充分做到某事的遗憾。

撮る→撮れば；撮ってよかった＝幸好拍了。

检测题

1. 「行こう」是什么形式？

  1. 可能形
  2. 意志形
  3. 被动形
  4. 否定形

答案 2　意志形，表示去吧、打算去。

  • 可能形是行ける。
  • ✓ 意志形，表示去吧、打算去。
  • 不是被动。
  • 没有否定。

行く→行こう。

2. 「終わらないうちに」是什么意思？

  1. 已经结束之后
  2. 一定不会结束
  3. 趁还没结束
  4. 为了立刻结束

答案 3　趁结束这个变化尚未发生。

  • 意思相反。
  • 不是保证永远不结束。
  • ✓ 趁结束这个变化尚未发生。
  • 不是催促结束。

ないうちに＝趁还没……。

3. 「聞くたびに」表示？

  1. 偶尔听一次
  2. 边听边做
  3. 刚听完
  4. 每次听的时候

答案 4　たびに表示每一次。

  • 偶尔是たまに。
  • 边听常用聞きながら。
  • 刚听完是聞いたばかり。
  • ✓ たびに表示每一次。

动词原形＋たびに。

4. 「残っている」在本句中表示？

  1. 保留的状态
  2. 马上删除
  3. 要求别人留下
  4. 完全消失

答案 1　记忆或景色仍留存。

  • ✓ 记忆或景色仍留存。
  • 没有删除。
  • 不是请求。
  • 与残る相反。

ている也可表示结果状态。

5. 「忘れないように書く」中的ように表示？

  1. 比喻
  2. 目的
  3. 听说
  4. 程度

答案 2　为了避免忘记而写。

  • 不是像……一样。
  • ✓ 为了避免忘记而写。
  • 不是传闻。
  • 不是程度。

否定形＋ように：为了不……。

6. 「撮ればよかった」与「撮ってよかった」有何区别？

  1. 都表示必须拍照
  2. 前者庆幸，后者后悔
  3. 前者遗憾没拍够，后者庆幸拍了
  4. 都表示不能拍照

答案 3　ばよかった表示遗憾；てよかった表示做过后觉得好。

  • 没有义务。
  • 两者颠倒。
  • ✓ ばよかった表示遗憾；てよかった表示做过后觉得好。
  • 没有禁止。

ばよかった与てよかった要区分。
