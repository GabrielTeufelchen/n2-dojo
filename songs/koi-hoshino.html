恋（こい）

星野源 · 2026-10-29

星野源 · 恋 · 官方原唱 MV

听星野源《恋》的官方原唱MV，练日常关系、时间和心情表达。下方6句为原创练习，未加入逐句歌词。

学习目标

  • 听辨轻快节奏中的长音与助词
  • 结合今日进阶课掌握うちに，区分间与期限
  • 用ことにする、とは限らない与おかげで描述生活选择

听辨

  • 第一遍完整听，留意旋律与舞蹈节拍的关系，辨认主歌和副歌。
  • 第二遍选自己听清的5～10秒回听，留意助词、长音和句末，不凭旋律猜字。
  • 第三遍跟读最清楚的短段；再用下方原创句练习时间、相处和日常决定。

Vocab

相处与生活。

  • 暮（く）らし　生活。
  • 習慣（しゅうかん）　习惯。
  • 支（ささ）える　支持、支撑。
  • 気持（きも）ち　心情、心意。

语法

  • 〜うちに：趁某状态持续时
  • 〜間に：在某段时间内发生
  • 〜までに：在期限前完成
  • 〜ことにする：主动决定
  • 〜とは限らない：未必、不一定
  • 〜おかげで：多亏……

逐句学习

原创迁移练习 · 以下6句不是歌词。

温（あたた）かいうちに、一緒（いっしょ）にご飯（はん）を食（た）べよう。

趁饭菜还热，一起吃吧。

温かいうちに＝趁还热；一緒に＝一起；食べよう＝吃吧。

い形容词＋うちに，强调抓住当前状态；与今日进阶课衔接。

冷めないうちに＝趁还没凉。

彼（かれ）が料理（りょうり）をしている間（あいだ）に、私（わたし）はテーブルを片付（かたづ）けた。

他做饭的时候，我收拾好了桌子。

料理をしている＝在做饭；間に＝在这段时间内；片付けた＝收拾了。

間に突出前项持续期间发生、完成后项；間则常描述两件事同时持续。

間に与うちに都可涉及时段，うちに更突出状态改变前的机会。

八時（はちじ）までに帰（かえ）れるように、早（はや）めに出発（しゅっぱつ）する。

为了能在八点前回去，我会早点出发。

までに＝在期限前；帰れる＝能回去；ように＝为了使；出発する＝出发。

可能形＋ように表示目标；までに是完成期限，不是持续到八点。

八時まで待つ＝等到八点；八時までに帰る＝八点前回去。

今週（こんしゅう）は、二人（ふたり）で食事（しょくじ）を作（つく）ることにした。

这周我决定两个人一起做饭。

二人で＝两个人一起；ことにした＝决定做。

动词原形＋ことにする表示主动决定；ことになる侧重形成的安排、结果。

否定决定：外食しないことにした＝决定不出去吃。

意見（いけん）が違（ちが）うからといって、仲（なか）が悪（わる）いとは限（かぎ）らない。

意见不同，并不代表关系不好。

意見が違う＝意见不同；からといって＝不能仅凭……；とは限らない＝不一定。

不能由前项就断定后项；否定普遍判断，不等于断言双方一定关系好。

仲が悪い＝关系不好；仲がいい＝关系好。

友達（ともだち）が手伝（てつだ）ってくれたおかげで、準備（じゅんび）が早（はや）く終（お）わった。

多亏朋友帮忙，准备很快就完成了。

手伝ってくれた＝朋友帮了我；おかげで＝多亏；準備が終わった＝准备结束了。

てくれる从接受帮助的一方看动作；おかげで通常引出令人满意的结果。

せいで常用于不好的后果；先分清语境中的评价。

检测题

1. 温かい（　）、スープを飲んでください。

  1. うちに
  2. までを
  3. ためが
  4. はずを

答案 1　趁汤还热的时候喝。

  • ✓ 趁汤还热的时候喝。
  • 接续不成立。
  • 接续不成立。
  • 接续不成立。

い形容词＋うちに：趁状态持续时。

2. 「料理をしている間に、片付けた」は？

  1. 料理结束后才收拾
  2. 做饭期间收拾了
  3. 从不收拾
  4. 必须自己做饭

答案 2　前项持续期间发生了后项。

  • 間に不是结束之后。
  • ✓ 前项持续期间发生了后项。
  • 没有否定。
  • 没有义务。

間に：在某段时间之内发生。

3. 「八時までに帰る」の意味は？

  1. 一直等到八点
  2. 八点以后再出发
  3. 在八点这个期限前回去
  4. 每天八点起床

答案 3　までに强调完成的期限。

  • 等到八点是八時まで待つ。
  • 不是之后出发。
  • ✓ までに强调完成的期限。
  • 没有起床。

区分まで与までに。

4. 「作ることにした」は？

  1. 已经习惯做
  2. 被禁止做
  3. 做过一次
  4. 主动决定做

答案 4　ことにした表示作出了决定。

  • 习惯常用ことにしている。
  • 没有禁止。
  • 经历是たことがある。
  • ✓ ことにした表示作出了决定。

ことにする：自己作出决定。

5. 「仲が悪いとは限らない」说明？

  1. 不一定关系不好
  2. 一定关系很好
  3. 一定关系不好
  4. 无法结交朋友

答案 1　否定必然性，不能直接推出相反极端。

  • ✓ 否定必然性，不能直接推出相反极端。
  • 不一定不好不等于一定很好。
  • 与否定必然相反。
  • 没有不能交友。

とは限らない＝未必。

6. 友達が手伝ってくれた（　）、早く終わった。

  1. せいで
  2. おかげで
  3. くせに
  4. わりには

答案 2　多亏朋友帮忙，得以早点完成。

  • 这里是感谢与良好结果。
  • ✓ 多亏朋友帮忙，得以早点完成。
  • 带不满，语境不合。
  • 用于与标准不相称，此处不合。

おかげで通常引出好结果。
