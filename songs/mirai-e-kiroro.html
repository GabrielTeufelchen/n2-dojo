Kiroro的1998年单曲《未来へ》。使用官方频道发布的完整原曲MV，练习家人、感谢与成长相关表达。下方6句为原创迁移练习，不是歌词。

学习目标

  • 听辨舒缓演唱中的长音与句尾
  • 区分おかげで的原因与ても的让步
  • 用て初めて与をきっかけに描述成长

听辨

  • 第一遍完整听，留意主歌和副歌的情绪变化。
  • 第二遍选5～10秒回听，辨认句尾元音拖长的位置；先按说话节奏模仿。
  • 第三遍跟唱同一短段，再用下方原创句讲一件值得感谢的事。

Vocab

感谢与成长

  • 支（ささ）え　支持
  • 感謝（かんしゃ）　感谢
  • 将来（しょうらい）　将来

语法

  • おかげで：有利原因
  • て初めて：经历后才
  • たびに：每次
  • さえ～ば：只要
  • ても：让步
  • をきっかけに：契机

逐句学习

原创迁移练习 · 以下6句不是歌词。

家族（かぞく）の支（ささ）えのおかげで、留学（りゅうがく）を続（つづ）けられた。

多亏家人的支持，我才得以继续留学。

支え＝支持；続けられた＝能够继续。

おかげで：有利的原因。

名词＋のおかげで。

親（おや）になって初（はじ）めて、育（そだ）てる大変（たいへん）さが分（わ）かった。

成为父母后，我才第一次明白养育孩子的辛苦。

大変さ＝辛苦的程度。

て初めて：直到经历前项，才明白后项。

な形容词去な＋さ。

将来（しょうらい）について考（かんが）えるたびに、先生（せんせい）の言葉（ことば）を思（おも）い出（だ）す。

每次思考将来，我都会想起老师的话。

について＝关于。

たびに：每次发生。

考える＋たびに。

時間（じかん）さえあれば、毎週（まいしゅう）実家（じっか）に帰（かえ）りたい。

只要有时间，我每周都想回老家。

実家＝父母家、老家。

さえ～ば：只需满足这个条件。

時間さえあれば＝只要有时间。

忙（いそが）しくても、感謝（かんしゃ）の気持（きも）ちを伝（つた）えることは忘（わす）れない。

即使忙碌，我也不会忘记表达感谢。

感謝の気持ち＝感谢的心意。

ても：即使；こと把动作名词化。

伝えることを忘れない；は强调该事项。

卒業（そつぎょう）をきっかけに、自分（じぶん）の生活（せいかつ）を見直（みなお）した。

以毕业为契机，我重新审视了自己的生活。

見直す＝重新审视。

をきっかけに：某事件成为变化的契机。

名词＋をきっかけに。

检测题

1. 「家族の支えのおかげで」は？

  1. 因为家人的阻挠
  2. 多亏家人的支持
  3. 虽然有家人支持
  4. 在家人支持以前

答案 2　有利原因。

  • 支え不是阻挠。
  • ✓ 有利原因。
  • 不是逆接。
  • 不是时间先后。

名词＋のおかげで。

2. 「親になって初めて分かった」は？

  1. 还没成为父母就懂了
  2. 永远不明白
  3. 成为父母后才懂了
  4. 每次成为父母都会忘记

答案 3　前项经历使后项认识成为可能。

  • 顺序相反。
  • 分かった是明白了。
  • ✓ 前项经历使后项认识成为可能。
  • 不是反复遗忘。

て初めて：经历后才。

3. 将来を考える（　）、先生を思い出す。

  1. ためだった
  2. ところだった
  3. ことなく
  4. たびに

答案 4　每次思考都会想起。

  • 不是该句的反复关系。
  • 表示即将等阶段，不合此意。
  • 会变成不思考。
  • ✓ 每次思考都会想起。

辞书形＋たびに。

4. 「時間さえあれば」は？

  1. 只要有时间
  2. 完全没有时间
  3. 时间越多越好
  4. 即使没时间

答案 1　提出最低必要条件。

  • ✓ 提出最低必要条件。
  • 不是否定。
  • 不是比例变化。
  • あれば是假设有。

さえ～ば：只要。

5. 「忙しくても、感謝を伝える」は？

  1. 因为闲所以感谢
  2. 忙碌是感谢的目的
  3. 即使忙也表达感谢
  4. 表达感谢后才忙

答案 3　前项成立仍做后项。

  • 没有闲的意思。
  • 不是目的。
  • ✓ 前项成立仍做后项。
  • 不是先后。

ても：让步。

6. 「卒業をきっかけに」は？

  1. 毕业造成的限制
  2. 以毕业为契机
  3. 只在毕业以前
  4. 拒绝毕业

答案 2　事件带来改变的起点。

  • 不是限制。
  • ✓ 事件带来改变的起点。
  • 不是时间截止。
  • 没有拒绝。

名词＋をきっかけに。
