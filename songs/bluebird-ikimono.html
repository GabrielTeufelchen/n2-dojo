いきものがかり · 2026-11-10

いきものがかり · ブルーバード · 官方原曲 Music Video

《火影忍者 疾风传》片头曲《ブルーバード》。使用官方原曲MV，练习出发、挑战与变化。下方6句为原创练习，不是歌词。

学习目标

  • 听辨快节奏中的促音与长音
  • 用に比べて比较过去和现在
  • 区分决心、尝试与变化的表达

听辨

  • 第一遍完整听，留意主歌进入副歌时节奏与力度的变化。
  • 第二遍选听清的5～10秒回听，辨认短暂停顿与拖长元音。
  • 第三遍先按说话速度模仿，再跟唱同一短段；用原创句表达自己的挑战。

Vocab

挑战与成长

  • 挑戦（ちょうせん）　挑战
  • 勇気（ゆうき）　勇气
  • 一歩（いっぽ）　一步

语法

  • に比べて：相比
  • ことにする：决定
  • ようとする：试图
  • ようになる：变化
  • としても：即使
  • ずに：不做

逐句学习

原创迁移练习 · 以下6句不是歌词。

去年（きょねん）に比（くら）べて、今年（ことし）は新（あたら）しいことに挑戦（ちょうせん）する機会（きかい）が増（ふ）えた。

与去年相比，今年挑战新事物的机会增加了。

機会が増える＝机会增加。

に比べて：以某对象为基准比较。

以前に比べて＝与以前相比。

怖（こわ）くても、まず一歩（いっぽ）踏（ふ）み出（だ）すことにした。

即使害怕，我也决定先迈出一步。

踏み出す＝迈出；まず＝首先。

ことにした：主动作出决定；ても表示让步。

踏み出した：已经迈出，不只决定。

鳥（とり）が空（そら）へ飛（と）び立（た）とうとしている。

鸟正要向天空飞去。

飛び立つ＝起飞。

意向形＋としている：正要做或正在尝试。

飛び立つ→飛び立とう。

練習（れんしゅう）を続（つづ）けて、人前（ひとまえ）でも話（はな）せるようになった。

坚持练习后，我在众人面前也能说话了。

人前＝众人面前；話せる＝能说。

可能形＋ようになる：获得某种能力。

話すようになった：开始经常说。

失敗（しっぱい）したとしても、その経験（けいけん）は無駄（むだ）にはならない。

即使失败，这段经历也不会白费。

無駄になる＝白费。

としても：假设前项成立，后项仍如此。

失敗したから＝因为失败，表示原因。

結果（けっか）を急（いそ）がずに、毎日（まいにち）少（すこ）しずつ進（すす）もう。

别急着求结果，每天一点点前进吧。

急ぐ＝着急；少しずつ＝一点点。

ない形去ない＋ずに：不做前项而做后项。

急がない→急がずに；する→せずに。

检测题

1. 「去年に比べて」は？

  1. 与去年相比
  2. 去年之前
  3. 只在去年
  4. 关于去年的传闻

答案 1　去年是比较基准。

  • ✓ 去年是比较基准。
  • 不是时间先后。
  • 没有限定。
  • 不是传闻。

名词＋に比べて。

2. 「踏み出すことにした」は？

  1. 被禁止迈步
  2. 决定迈出一步
  3. 从未走过
  4. 已经走了很久

答案 2　主动作决定。

  • 没有禁止。
  • ✓ 主动作决定。
  • 不是经历否定。
  • 不是持续。

ことにした：决定。

3. 飛び立つ的意向形是？

  1. 飛び立て
  2. 飛び立ちたい
  3. 飛び立とう
  4. 飛び立って

答案 3　五段つ→とう。

  • 命令形。
  • 愿望形。
  • ✓ 五段つ→とう。
  • て形。

意向形＋とする。

4. 「話せるようになった」は？

  1. 被迫说话
  2. 不再说话
  3. 正在写字
  4. 变得能说话了

答案 4　能力变化。

  • 没有被迫。
  • 没有否定。
  • 不是写字。
  • ✓ 能力变化。

可能形＋ようになる。

5. 「失敗したとしても」は？

  1. 即使失败
  2. 因为成功
  3. 失败之后才
  4. 不能失败

答案 1　假设并让步。

  • ✓ 假设并让步。
  • 不是成功原因。
  • 不是单纯先后。
  • 没有禁止。

としても：即使。

6. 急がない→ずに形式是？

  1. 急ぎずに
  2. 急がずに
  3. 急ぐずに
  4. 急いずに

答案 2　急がない去ない＋ずに。

  • 保留ない形词干。
  • ✓ 急がない去ない＋ずに。
  • 不能接辞书形。
  • 不是い形。

ない形去ない＋ずに。
